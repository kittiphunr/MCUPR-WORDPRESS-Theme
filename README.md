# MCUPR-S.A.T.U.R.N (WordPress Theme)

ธีม WordPress สำหรับเว็บไซต์หน่วยงานภาครัฐ/สถาบันการศึกษา โครงสร้างหน้าเว็บอ้างอิง [www.chula.ac.th](https://www.chula.ac.th/)
(แถบเครื่องมือด้านบน → โลโก้/ชื่อหน่วยงาน → เมนูหลักแบบหลายระดับ → ข่าวเด่น + หัวข้อข่าว → ลิงก์ด่วน → ข่าวล่าสุด → ท้ายเว็บไซต์)

โฟลเดอร์ธีมคือ `mcupr/` — zip โฟลเดอร์นี้แล้วอัปโหลดที่ *Appearance → Themes → Add New → Upload*

## เทคโนโลยี UI

- **Tailwind CSS v4** เป็นแกนของ UI ทั้งหมด — ใส่ utility class ในเทมเพลตโดยตรง (ใช้ `@apply` เฉพาะมาร์กอัปที่ WordPress สร้างเอง เช่น เมนู, เนื้อหาในตัวแก้ไข, pagination, ฟอร์มคอมเมนต์) สี/โหมดมืด/โหมดคอนทราสต์ผูกกับ CSS variables ผ่าน `@theme` จึงใช้ utility ปกติ (`bg-bg`, `text-fg`, `bg-primary` …) ได้ทุกโหมด
- **SweetAlert2** ใช้สำหรับการแจ้งเตือนทั้งหมด: ประกาศคุกกี้/PDPA, ยืนยันการรีเซ็ตการตั้งค่า, toast แจ้งสถานะ (เช่น ขนาดอักษร), เตือนเมื่อค้นหาโดยไม่ใส่คำ — ไฟล์เก็บในธีม (`assets/vendor/`) ไม่โหลดจาก CDN
- ไฟล์ CSS ที่ build แล้ว (`mcupr/assets/css/tailwind.css`) ถูก commit ไว้ ติดตั้งธีมได้เลยโดยไม่ต้องมี Node

### โครงสร้างรีโป

```
mcupr/            ← ธีมที่ติดตั้งจริง (มีเฉพาะไฟล์ที่ใช้งาน)
  functions.php   ← ตัวโหลด + ตรวจเวอร์ชันขั้นต่ำ (inc/compat.php)
  inc/            ← setup, assets, i18n, colors, customizer, widgets, shortcodes, seo, dates ...
  template-parts/ assets/ (css, js, fonts, vendor)  readme.txt  screenshot.jpg
src/input.css     ← ต้นฉบับ Tailwind (ไม่อยู่ในไฟล์ติดตั้ง)
scripts/package.sh← สร้างไฟล์ zip สำหรับติดตั้ง
tests/            ← ชุดทดสอบ (ไม่อยู่ในไฟล์ติดตั้ง)
package.json      ← คำสั่ง build/package
```

### แก้ไขสไตล์ / สร้างไฟล์ติดตั้ง

```bash
npm install
npm run watch     # หรือ npm run build ก่อน commit
npm run vendor    # คัดลอก sweetalert2 จาก node_modules (เมื่ออัปเดตเวอร์ชัน)
npm run package   # → dist/mcupr-<เวอร์ชัน>.zip  (Appearance → Themes → Add New → Upload Theme)
```

**ทุกครั้งที่ออกเวอร์ชันใหม่ให้เพิ่มเลขเวอร์ชัน** (WordPress จะไม่อัปโหลดธีมที่เวอร์ชันซ้ำกับที่ติดตั้ง): `bash scripts/bump-version.sh 1.1.1 "สิ่งที่เปลี่ยน"` แก้ให้ครบทั้ง style.css / functions.php / package.json / changelog (`tests/check.sh` ตรวจว่าตรงกัน) แล้วค่อย `npm run package`

ต้นฉบับอยู่ที่ `src/input.css` — เพิ่ม/แก้ class ในเทมเพลต `.php` หรือ `mcupr/assets/js/main.js` แล้ว build ใหม่ ไฟล์ zip มีเฉพาะโฟลเดอร์ `mcupr/` (ไม่มี node_modules / src / tests) ธีมไม่ยอมเปิดใช้บน WordPress < 5.9 หรือ PHP < 7.0 (ทดสอบชุดเต็มบน WordPress 5.9.9 และ 6.2.2 จริง รวมถึงรุ่นล่าสุด) (ตรวจโค้ดด้วย PHPCompatibility ตั้งแต่ PHP 7.0 ขึ้นไป) (จะย้อนกลับธีมเดิมพร้อมข้อความอธิบาย) และมีสไตล์พรีวิวในตัวแก้ไขบล็อก

## อินเทอร์เฟซแบบ Certify Hub + ผู้เข้าชมปรับเองได้

นำแนวทางอินเทอร์เฟซของโปรเจกต์ [Certify Hub](https://github.com/kittiphunr/certify-hub) (แนว Formsmith) มาใช้: พื้นหลังสีเทาอมน้ำเงินอ่อน (slate) + **การ์ดขาวมุมโค้ง**, แถบหัวติดขอบบนโปร่งแสง, **โลโก้ในป้ายมุมโค้ง** + ชื่อ/ชื่อรอง, เมนูแบบ **pill** (รายการปัจจุบันเป็นสีอ่อน), ปุ่มไอคอนสี่เหลี่ยมมุมโค้ง (ค้นหา · ภาษา · **ตั้งค่าการแสดงผล** · **เกี่ยวกับ**), แถบเมนูด้านข้างแบบกลุ่มลอย, ฟอนต์ Sarabun (ฝังในธีม) และเครดิตท้ายเว็บ

**ภาษาภาพแบบเดียวกับ Certify Hub:** การ์ดมนใหญ่ไร้ขอบเงานุ่ม (โหมดมืด/คอนทราสต์ใช้เส้นขอบบางแทน) ยกตัวเมื่อชี้, ฟุตเตอร์เป็นการ์ดเดียว, ปุ่ม/ช่องค้นหาทรงแคปซูล, ตัวกรองหมวดเป็นแท็บแคปซูล (ตัวที่เลือกเป็นสีหลักเรืองแสง), หน้า 404/ไม่พบข้อมูลเป็นการ์ดสถานะไอคอนกลม

**หน้าบทความเดี่ยว + ความคิดเห็น:** แถบเครื่องมือ (แชร์/คัดลอกลิงก์/พิมพ์) เป็นแคปซูล, ข้อมูลวันที่/เวลาอ่านมีไอคอน, แท็กเป็นเม็ดยา, ปุ่มบทก่อนหน้า/ถัดไปเป็นการ์ดยกตัว; ความคิดเห็นเป็นการ์ดเดียว แต่ละความเห็นเป็นบับเบิลมีตัวอักษรย่อในวงกลม (ไม่เรียก Gravatar จึงไม่ส่งข้อมูลผู้เข้าชมไปบุคคลที่สาม ตาม PDPA), ตอบกลับซ้อนชั้น, ฟอร์มช่องกรอกมนแคปซูลพร้อมป้ายกำกับทุกช่อง ปุ่มส่งทรงแคปซูล และข้อความทั้งหมดแปลครบ 4 ภาษา

**แผงตั้งค่าและหน้าเพจ:** แผงตั้งค่าแบ่งเป็น 3 กลุ่มใต้ป้ายตัวพิมพ์ใหญ่เล็ก (การแสดงผล / ตัวอักษร / การเข้าถึง) กล่องโต้ตอบมุมมนใหญ่ เงานุ่ม ปุ่มทรงแคปซูล; หน้าเพจมีแถบเครื่องมือแคปซูล รายการ “ในหมวดนี้” เป็นเมนูแคปซูลที่หน้าปัจจุบันเรืองสีหลัก และหน้าแรกของหมวดแสดงหน้าย่อยเป็นการ์ด (tile)

**หน้าแรก:** หัวข้อแต่ละส่วนมีไอคอนกลม, ข่าวเด่นเป็นสไลด์เลื่อนแนวนอนพร้อมปุ่มลูกศรกลม, ข่าวสารมีแท็บหมวดแคปซูลและการ์ดข่าวแรกขนาดใหญ่, แบนเนอร์ท้ายหน้าเป็นการ์ดสีหลักพร้อมปุ่มแคปซูลสีกลับ

**เมนูหลักแถบบนพอดีความกว้าง:** เมนูอยู่แถวเดียวเสมอ รายการที่ไม่พอที่จะย้ายเข้าเมนู “เพิ่มเติม” อัตโนมัติ (คำนวณใหม่เมื่อย่อ/ขยายหน้าจอ เปลี่ยนขนาดอักษร หรือเปลี่ยนตำแหน่งเมนู; ปิดด้วย Esc หรือคลิกข้างนอกได้) ชื่อหน่วยงานที่ยาวจะขึ้นสองบรรทัดแทนการบีบเมนู; ต่ำกว่า 1100px ใช้ลิ้นชักแสดงเมนูครบ

**จัดการเมนู: ไอคอน + Mega menu** (Appearance → Menus, ไม่ต้องใช้ปลั๊กอิน)
- **ไอคอนหน้าข้อความ:** ทุกรายการเมนูมีช่อง “Icon before the text” เลือกจากไอคอน 39 แบบ (หมวกบัณฑิต หนังสือ ปฏิทิน อาคาร ฯลฯ) แสดงทั้งแถบบน แถบข้าง ลิ้นชัก เมนูท้ายเว็บ และเมนูลิงก์ด่วน (รายการที่ไม่ได้เลือกไอคอนจะไม่มีไอคอนบนแถบบน)
- **Mega menu:** ติ๊ก “Show the sub-menu as a mega menu” ที่รายการระดับบนสุดของเมนูหลัก เลือก 2/3/4 คอลัมน์ — รายการระดับสองที่มีลูกคือหัวคอลัมน์ ลูกของมันคือลิงก์ในคอลัมน์ รายการระดับสองที่ไม่มีลูกเป็นลิงก์เดี่ยว; เปิด “Description” ใน Screen Options เพื่อใส่บรรทัดอธิบายใต้ลิงก์
- แผงเต็มความกว้างของแถบหัว ปิดด้วย Esc/คลิกข้างนอก; บนแถบข้าง/โหมดผสม/มือถือ จะเป็นรายการซ้อนแบบพับได้เหมือนเดิม และถ้าถูกย้ายเข้าเมนู “เพิ่มเติม” จะเป็นเมนูย่อยปกติ
**กล่อง “เกี่ยวกับเว็บไซต์” แบบ Precision QC:** หัวกล่อง (โลโก้ + “เกี่ยวกับ {หน่วยงาน}”), ผู้พัฒนา (รูปกลมหรือตัวอักษรย่อ ชื่อ ตำแหน่ง แท็กสั้น และช่องทางติดต่อ), เกี่ยวกับเว็บไซต์ (ข้อความ รายการความสามารถ ชิปส่วนประกอบ), เทคโนโลยีและทรัพยากรที่นำมาใช้พร้อมสัญญาอนุญาต, สิทธิ์และการอ้างอิง (GPL, ตราสัญลักษณ์, ความเป็นส่วนตัว, ลิงก์นโยบาย), หน่วยงานและติดต่อ พร้อมเวอร์ชันธีม — ครบ 4 ภาษา ตั้งข้อมูลผู้พัฒนา/ช่องทางติดต่อที่ Customizer → *MCUPR: Organisation & languages* (ว่างไว้ = ไม่แสดงส่วนผู้พัฒนา ไม่มีข้อมูลส่วนบุคคลติดมากับธีม)

**หน้าแรกครบในตัว (ไม่ต้องตั้ง “หน้าแรกแบบหน้าตายตัว” ใน Settings → Reading):** ใช้ `front-page.php` ทั้งโหมด “เรื่องล่าสุดของคุณ” และโหมดหน้าตายตัว — ประกอบด้วย Hero + ลิงก์ด่วน (ถ้ายังไม่ตั้งเมนู Quick links จะใช้รายการแรกของเมนูหลัก), บล็อกแนะนำหน่วยงาน (ข้อความ “เกี่ยวกับ” + ปุ่มไปหน้าที่เลือก), ข่าวเด่นแบบสไลด์, ข่าวสารและกิจกรรม (การ์ดแรกใหญ่ + แท็บหมวด), ข่าวแยกหมวด 3 บล็อก (เลือกหมวดเองหรืออัตโนมัติตามจำนวนข่าว ข้ามหมวด Uncategorized), พื้นที่วิดเจ็ต, ติดต่อและที่ตั้ง (ที่อยู่ โทร อีเมล) และแบนเนอร์ท้ายหน้า ส่วนที่ไม่ได้กรอกข้อมูลจะหายไปเอง; ปุ่ม “ดูข่าวทั้งหมด” ใช้ได้แม้ไม่มีหน้า Posts page (`?mcupr_all=1` แสดงข่าวทั้งหมดแบบแบ่งหน้า) ตั้งค่าที่ Customizer → *MCUPR: Home hero & banner*

**ผู้เข้าชมเลือกการแสดงผลเองได้** (ปุ่มปรับแต่ง ⚙ บนแถบหัว → จำค่าในเบราว์เซอร์ ไม่ต้องล็อกอิน):
- **ตำแหน่งเมนู**: *แถบด้านบน* (แถบลอยทรงแคปซูล ปุ่มเมนูปัจจุบันเป็นสีหลักเรืองแสง), *แถบด้านข้าง* หรือ **แบบผสม (Hybrid)** = แถบลอยด้านบน (โลโก้ + เครื่องมือ) คู่กับแถบไอคอนบางๆ ด้านซ้ายที่ขยายด้วยปุ่มด้านล่าง (มือถือใช้ลิ้นชัก) — ตั้งค่าเริ่มต้นได้ที่ Customizer · (เดสก์ท็อป: แถบซ้ายคงที่ ยุบเหลือแต่ไอคอนได้ กดปุ่มด้านล่างเพื่อขยาย (ไม่ขยายเมื่อชี้เมาส์); มือถือ: ลิ้นชัก + ปุ่มลอยมุมซ้ายล่าง) — ผู้ดูแลตั้งค่าเริ่มต้นได้ที่ Customizer → MCUPR: Animation, news & reading
- **สีของเว็บไซต์**: ชุดสีสำเร็จรูป 6 แบบ (รวม *Indigo (Certify Hub)*) หรือ **เลือกสีเองได้ทุกสี** — ธีมคำนวณสีตัวอักษรบนปุ่มและสีลิงก์ให้ผ่านคอนทราสต์ ≥ 4.5:1 ทั้งโหมดสว่าง/มืดโดยอัตโนมัติ (ทดสอบกับสีเหลืองอ่อน เทากลาง ดำ ขาว) และโหมดคอนทราสต์สูงยังชนะสีที่เลือกเสมอ
- ธีม สว่าง/มืด/ตามระบบ · ขนาดตัวอักษร 5 ระดับ · โหมดสีตัดกันสูง · แอนิเมชัน เปิด/ปิด · ตัวเลือกเพิ่มเติม (สีเทา, ขีดเส้นใต้ลิงก์, ฟอนต์อ่านง่าย, ระยะห่าง, เคอร์เซอร์ใหญ่, ซ่อนรูป, โหมดทีวี) — **ทุกฟังก์ชันเดิมยังอยู่ครบ** (4 ภาษา, ค้นหาเต็มจอ, ฟังข่าว, วันที่ พ.ศ., หน้าข่าว 3 รูปแบบ, TV/4K ฯลฯ)
- **เกี่ยวกับ**: กล่องข้อมูลหน่วยงาน (ข้อความ/ที่อยู่/ลิงก์นโยบาย/เครดิต/เวอร์ชันธีม) ตั้งข้อความได้ที่ Customizer → MCUPR: Organisation (About text, Site credit)

**สีเริ่มต้นเป็นชมพู** (ชุด “ชมพู–ทอง” `#c2185b` + ทอง) และมี **ลวดลายพื้นหลังดอกอโศก**: กระจุกดอกอโศกพร้อมเกสรยาวและใบประกอบแบบขนนก วาดเป็น SVG ฝังในธีม (ไม่ต้องโหลดไฟล์ภาพ) ทั้งดอกและใบใช้ **สีหลักของเว็บสีเดียวกันเฉดเดียว** (ชมพูก็ชมพูล้วน ไม่มีสีอื่นแทรก) จางๆ และมีม่านสีพื้นหลังบางๆ ตรงกลางหน้า ลายจึงอยู่รอบขอบหน้าและเงียบลงหลังคอลัมน์ข้อความ ไม่รบกวนการอ่าน มองเห็นบนพื้นหลังระหว่างการ์ด/แถบ — **ซ่อนอัตโนมัติ** ในโหมดสีตัดกันสูง, เมื่อซ่อนรูปภาพ และตอนพิมพ์; ผู้เข้าชมซ่อนได้ที่ ตั้งค่าการแสดงผล → ตัวเลือกเพิ่มเติม → “ซ่อนลวดลายดอกอโศกพื้นหลัง” และผู้ดูแลตั้งค่าเริ่มต้นเป็นซ่อนได้ที่ Customizer

## เอกลักษณ์มหาจุฬาลงกรณราชวิทยาลัย

ธีมนี้ไม่ได้ลอกเว็บจุฬาฯ แต่ใช้ **โทนสีร่วม** (ชมพู–ทอง) ตามที่มีจุดเริ่มต้นจากพระมหากษัตริย์พระองค์เดียวกัน แล้วสร้างลวดลายและการจัดหน้าเฉพาะ: ลายเส้น **ตราสัญลักษณ์มหาวิทยาลัย** จางๆ (สีหลักสีเดียว) เป็นลายน้ำบนแถบหัวหน้า/หัวข่าว, หัวข้อมีเส้นไล่สีชมพู→ทอง, การ์ดข่าวมีแถบทองด้านบน

- **สีปรับได้ที่ Customizer → Colors**: ชุดสีสำเร็จรูป 4 แบบ (ชมพู–ทอง *ค่าเริ่มต้น*, เลือดหมู–ทอง, น้ำเงินราชนาวี–ทอง, กาสาวพัสตร์–ถ่าน, อินดิโก (Certify Hub), เขียวน้ำทะเล–อำพัน) หรือ *Custom* เลือกเอง 4 สี (สีหลัก, สีเน้น, พื้นมืด/ท้ายเว็บ, พื้นอ่อน) — **สีตัวอักษรบนสีหลักและสีลิงก์คำนวณให้อัตโนมัติ** ให้ผ่านคอนทราสต์ WCAG AA (≥ 4.5:1) ทั้งโหมดสว่างและมืด แม้ผู้ดูแลเลือกสีอ่อนมาก/สีกลางๆ (ทดสอบแล้ว)
- **โลโก้**: ค่าเริ่มต้นเป็น **ตราสัญลักษณ์มหาวิทยาลัย** (`mcupr/assets/img/mcu-logo.svg` ใช้ทั้งหัวเว็บ ท้ายเว็บ กล่องเกี่ยวกับ และไอคอนแท็บเบราว์เซอร์ จนกว่าจะอัปโหลดโลโก้/Site Icon ของตัวเอง) เปลี่ยนที่ Site Identity; เพิ่ม *โลโก้โหมดมืด*, *โลโก้ท้ายเว็บ* และปรับ *ความสูงโลโก้* ได้ที่ Customizer → MCUPR: Logos
- **แอนิเมชัน**: ผู้เข้าชมปิด/เปิดได้ด้วยสวิตช์ “แอนิเมชัน” ในกล่องตัวช่วยการเข้าถึง (จำค่าไว้) และผู้ดูแลตั้งค่าเริ่มต้นของเว็บเป็น *ปิด* ได้ (Customizer → MCUPR: Animation, news & reading); ระบบ “ลดการเคลื่อนไหว” ของอุปกรณ์ถูกเคารพเสมอ
- **วันที่แบบราชการไทย (ฝังในธีม ไม่ต้องใช้ปลั๊กอิน)**: เมื่อหน้าเป็นภาษาไทย ทุกวันที่ (ข่าว, การ์ด, ความคิดเห็น, ปีท้ายเว็บ) แสดงชื่อเดือน/วันภาษาไทยและ **พ.ศ.** เช่น `14 ตุลาคม 2569`, หน้าข่าวแสดง `วันอังคารที่ 14 ตุลาคม พ.ศ. 2569 เวลา 09.30 น.`; แอตทริบิวต์ `datetime=""` ยังเป็น ISO 8601 (ค.ศ.) สำหรับเครื่องอ่าน
- **หน้าข่าว 3 รูปแบบ** (ตั้งค่าเริ่มต้นที่ Customizer และเลือกรายข่าวได้ที่กล่อง *News layout* ในหน้าแก้ไขข่าว):
  1. **Reader** – คอลัมน์เดียวกึ่งกลาง ตัวอักษรใหญ่ บรรทัดสบายตา เหมาะอ่านยาว
  2. **Cover** – ภาพปกเต็มจอพร้อมชื่อข่าวทับ และแถบเครื่องมือ (ฟัง/แชร์/พิมพ์) แบบติดข้างขณะเลื่อน
  3. **Sidebar** – บทความด้านซ้าย ข่าวที่เกี่ยวข้อง/ข่าวล่าสุด/หมวดหมู่ด้านขวา
  ทุกแบบมี: ป้ายหมวด, วันที่ พ.ศ., เวลาอ่านโดยประมาณ, แชร์ (Facebook, LINE, คัดลอกลิงก์, แชร์ของอุปกรณ์), พิมพ์, ข่าวก่อนหน้า/ถัดไป, ข่าวที่เกี่ยวข้อง
- **หน้าเพจ**: แถบหัวสีอ่อนพร้อมลายน้ำตราสัญลักษณ์มหาวิทยาลัย (`mcupr/assets/img/mcu-seal.svg`), รายการ “ในหมวดนี้” (หน้าแม่/หน้าลูกในกลุ่มเดียวกัน), วันที่ปรับปรุงล่าสุด (พ.ศ.), ปุ่มพิมพ์ · **หน้าข่าวทั้งหมด/หมวด/แท็ก**: ดู “เบราว์เซอร์ข่าวแบบ Finder” ด้านล่าง
- **ฟังข่าว (อ่านออกเสียง)**: ปุ่ม “ฟังเนื้อหานี้” ในข่าวและเพจ ใช้ระบบอ่านออกเสียงของเบราว์เซอร์ (Web Speech API — ไม่ใช้ปลั๊กอิน ไม่ส่งข้อมูลออกนอกเครื่อง) อ่านชื่อเรื่องแล้วไล่ทีละหัวข้อ/ย่อหน้า/รายการ พร้อมไฮไลต์ย่อหน้าที่กำลังอ่าน, หยุดชั่วคราว/เล่นต่อ/หยุด, ความเร็ว 0.75–1.5×, เลือกเสียงตามภาษาของเนื้อหา (th/en/zh/ja); ปิดได้ที่ Customizer
  - *ข้อจำกัด*: คุณภาพ/การมีเสียงภาษาไทยขึ้นกับอุปกรณ์ (เช่น Android/Chrome, iOS/Safari, Windows มีเสียงไทย; บางเครื่องไม่มี) — ถ้าไม่พบเสียงจะแจ้งผู้ใช้ ธีมไม่ได้ฝังเสียงสังเคราะห์ของตัวเอง

## เมนูและกล่องโต้ตอบ (อ้างอิงเว็บ chula.ac.th) + แอนิเมชัน

- **Header สีขาว**: โลโก้ + ชื่อ 2 ภาษา, เมนูหลักกึ่งกลางพร้อมลูกศร dropdown, ไอคอนด้านขวา **Aa** (ตัวช่วยการเข้าถึง) · **โลก + ป้ายภาษา** · **แว่นขยาย** · ปุ่มเมนู (ต่ำกว่า 1100px เมนูเป็น **drawer เลื่อนจากขวา** พร้อมลูกศร → ต่อรายการ)
- **ตัวช่วยการเข้าถึง** (กล่อง SweetAlert2): ขนาดตัวอักษร 5 ระดับเป็นปุ่มวงกลม **A**, สวิตช์ “โหมดสีตัดกันสูง” (+ เลือกขาว/เหลืองบนดำ, ดำบนเหลือง), โหมดแสดงผล ตามระบบ/สว่าง/มืด, “ตัวเลือกเพิ่มเติม” (สีเทา, ขีดเส้นใต้, ฟอนต์อ่านง่าย, ระยะห่าง, เคอร์เซอร์ใหญ่, ลดการเคลื่อนไหว, ซ่อนรูป, โหมดทีวี) และลิงก์ “คืนค่าเริ่มต้น”
- **ภาษา**: กล่องเลือกภาษาแบบปุ่ม · **ค้นหา**: กล่องเต็มจอ ช่องค้นหา + “การค้นหาล่าสุด” (เก็บในเบราว์เซอร์) + “การค้นหายอดนิยม” (ตั้งที่ Customizer)
- **เอฟเฟกต์เหมือนโปรเจกต์ kittiphunr.github.io**: *เคอร์เซอร์โต้ตอบ* (จุด + วงแหวนตามเมาส์ ขยายเหนือลิงก์/ปุ่ม และเป็นบับเบิล “ดู” เหนือการ์ด), *scroll reveal* ไล่ทีละใบ, *การ์ดเอียง 3 มิติ + แสงวาว*, *เลื่อนหน้าแบบ ease*, แถบ progress การเลื่อน, ข้อความ Hero ค่อยๆ ขึ้น
  - เอฟเฟกต์ทั้งหมด **ปิดเมื่อ** ผู้ใช้ตั้งลดการเคลื่อนไหว (ระบบ/ตัวเลือก), โหมดคอนทราสต์สูง, ตัวเลือกเคอร์เซอร์ใหญ่, โหมดทีวี, และไม่ทำงานบนอุปกรณ์สัมผัส
- ไอคอนบนไทล์ Hero: ใส่ CSS class `icon-edit | book | bulb | money | bank | user | users | calendar | mail | cap | news` ที่รายการเมนู Quick links

## หน้าตา (อ้างอิงภาพหน้าจอ chula.ac.th)

หน้าแรก: เมนูหลักลอยบนภาพ Hero เต็มจอ + หัวข้อ 2 บรรทัด + ไทล์ลิงก์ด่วนแบบกระจกฝ้า → สไลด์ข่าวเด่น (เลื่อนด้วยปุ่ม/คีย์บอร์ด ไม่เล่นอัตโนมัติ) → ข่าวสารและกิจกรรม (ปุ่ม “ดูทั้งหมด” ทรงแคปซูล) → แบนเนอร์สีชมพูอ่อน → ท้ายเว็บสีดำแบ่งคอลัมน์

ตั้งค่าที่ Customizer → *MCUPR: Home hero & banner* (ภาพ Hero, หัวข้อ 2 บรรทัด, ข้อความแบนเนอร์ — แยกตามภาษา) เมนู **Quick links** = ไทล์บน Hero, เมนู **Footer links** = คอลัมน์ท้ายเว็บ (รายการระดับบนเป็นหัวคอลัมน์ ระดับรองเป็นลิงก์), เมนู **Utility bar** = ลิงก์นักศึกษา/บุคลากร/ศิษย์เก่า ที่แถบบน

## รองรับหน้าจอ 240px – 4K / ทีวี

| ความกว้าง | พฤติกรรม |
|---|---|
| 240–399px | เลย์เอาต์คอลัมน์เดียว ขอบแคบ ปุ่มและแถบเครื่องมือตัดบรรทัดอัตโนมัติ ไม่มีการเลื่อนแนวนอน |
| 400–899px | มือถือ/แท็บเล็ต เมนูแบบปุ่ม “เมนู” |
| 900–1599px | เดสก์ท็อป (เมนูแนวนอน, ไทล์ Hero 7 ช่อง) |
| ≥1600px | ขยายขนาดอักษรและ UI ทั้งหมดเป็นขั้น: 1600→110%, 1920→125%, 2560→165%, 3200→200%, **3840 (4K)→240%** และขยายความกว้างเนื้อหาเป็น 90rem — ทุกอย่างใช้หน่วย `rem` จึงขยายตามสัดส่วน (ทีวี 4K ที่รายงานเป็น 1920px @2x จะได้ 125%) |

ขนาดสุดท้าย = ขั้นตามหน้าจอ × ปุ่ม A−/A+ ของผู้ใช้ × โหมดทีวี

**โหมดทีวี (10-foot UI)** เปิดอัตโนมัติเมื่อตรวจพบเบราว์เซอร์ทีวี (Tizen, webOS, Android TV/Google TV, VIDAA, Fire TV, HbbTV, Roku, PlayStation/Xbox ฯลฯ) หรือเปิดเองที่แผง “การเข้าถึง → โหมดทีวี”: ตัวอักษรใหญ่ขึ้นอีก 20%, ปุ่ม/เมนูสูงอย่างน้อย 4rem, กรอบโฟกัสหนา 6px, ขอบปลอดภัย (overscan) 4% ซ้าย–ขวา, ธีมมืดโดยค่าเริ่มต้น, และ **เลื่อนโฟกัสด้วยปุ่มลูกศรของรีโมท** (spatial navigation) พร้อมปุ่ม Back (Tizen/webOS) ปิดแผงหรือย้อนกลับ

## เมนู: Mega menu + เมนูเต็มจอ

- **Mega menu** (Appearance → Menus → ติ๊ก “แสดงเมนูย่อยเป็น mega menu”) แผงเต็มความกว้างหัวเว็บ หัวคอลัมน์ = รายการระดับ 2 และเปิดได้ครั้งละหนึ่งแผงเท่านั้น
- **ปุ่ม “เมนูทั้งหมด”** (แถบบนของเดสก์ท็อป) เปิดเมนูทั้งหมดเต็มจอเป็นการ์ดต่อหมวด — สร้างจากเมนูหลักเมื่อกดครั้งแรก (ไม่กระทบความเร็วหน้าเว็บ), Esc ปิด, โฟกัสวนอยู่ในกล่อง, รวมรายการที่ถูกย้ายไป “เพิ่มเติม” ปิดปุ่มได้ที่ Customizer → MCUPR: Organisation & languages
- ถ้าเมนูกว้างเกินแถบ รายการที่ล้นจะอยู่ใน “เพิ่มเติม” และเมนูย่อยกางต่อในแผงเดียวกัน

## ฟุตเตอร์: ข้อมูลติดต่อ + แผนที่ Google Maps

ฟุตเตอร์แสดง ชื่อหน่วยงาน, ที่อยู่, โทรศัพท์ (แตะเพื่อโทร), อีเมล, เวลาทำการ, การ์ดแผนที่ และลิงก์นโยบาย — แก้ที่ Customizer → *MCUPR: Organisation & languages*: ที่อยู่ / เวลาทำการ (แยก 4 ภาษา), โทรศัพท์, อีเมล, “ตำแหน่งแผนที่” (ชื่อสถานที่ ที่อยู่ หรือ `ละติจูด,ลองจิจูด`) และปุ่มปิดแผนที่
- ค่าเริ่มต้นเป็นข้อมูลวิทยาเขตแพร่ (111 หมู่ที่ 5 ต.แม่คำมี อ.เมืองแพร่ 54000, โทร 054 646 273, จันทร์–ศุกร์ 08.30–16.30 น.) จนกว่าจะกรอกของตัวเอง — **ตรวจเวลาทำการให้ตรงกับหน่วยงาน**; เปลี่ยนค่าเริ่มต้นด้วย filter `mcupr_contact_defaults`
- **แผนที่โหลดเมื่อกด “แสดงแผนที่” เท่านั้น** — ไม่มีการเชื่อมต่อ Google และไม่มี iframe ตอนโหลดหน้า (คะแนนความเร็วไม่เสีย และเข้ากับ PDPA); มีลิงก์ “เปิดใน Google Maps” และ “เส้นทาง” เสมอ
- ลิงก์นโยบายที่อยู่ในเมนูฟุตเตอร์แล้วจะไม่แสดงซ้ำในคอลัมน์ท้าย

## ธีมเดี่ยว (ไม่ต้องพึ่งปลั๊กอิน) + Shortcode

ธีมทำงานได้ครบด้วยตัวเอง ไม่ผสานกับ Polylang / Elementor / Yoast / Rank Math:
- **หลายภาษา:** ตัวสลับภาษาในตัว + กล่อง Translations ใต้ตัวแก้ไข + `hreflang` (ดูตารางฟังก์ชัน)
- **SEO พื้นฐานในตัว** (`inc/seo.php`): meta description, Open Graph / Twitter card, `noindex` ผลค้นหา (ปิดได้ด้วย `add_filter( 'mcupr_seo', '__return_false' )`)
- **เบรดครัมบ์** ของธีมเอง
- **วิดเจ็ต “เรื่องล่าสุด” (Recent Posts)** ธีมวาดเอง: ชื่อเรื่องตัดที่ 30 ตัวอักษร (ไม่ตัดสระ/วรรณยุกต์ขาดจากพยัญชนะ) ตามด้วยปุ่ม “อ่านต่อ...” (ชื่อเต็มอยู่ใน aria-label) — เปลี่ยนความยาวด้วย `add_filter( 'mcupr_recent_title_length', fn() => 40 )`

### แทรก shortcode
- **ช่องในตัวปรับแต่ง** Customizer → *MCUPR: Shortcodes & HTML areas* วาง `[shortcode]` (ของธีมหรือปลั๊กอินใดก็ได้) หรือ HTML ได้ 4 จุด: ใต้ส่วนหัวทุกหน้า, หน้าแรกใต้ Hero, ท้ายบทความ/หน้า, เหนือฟุตเตอร์ (ว่าง = ไม่แสดง)
- **วิดเจ็ต** (Text / Custom HTML) และเนื้อหาโพสต์/หน้า รัน shortcode ได้อยู่แล้ว
- **shortcode ของธีม:** `[mcupr_tools]` (ปุ่มภาษา/ขนาดอักษร/โหมดมืด/การเข้าถึง/ค้นหา), `[mcupr_news count="3" category="slug" columns="3"]` (การ์ดข่าวล่าสุด), `[mcupr_button url="/ติดต่อ/" style="solid|outline"]ข้อความ[/mcupr_button]`, `[mcupr_stats items="users|12,500|นักศึกษา; cap|40|หลักสูตร"]` (การ์ดตัวเลขไอคอนกลม — ชื่อไอคอน: edit, book, bulb, money, bank, user, users, calendar, mail, cap, news, globe …)
- **shortcode ของหน้าแบบราชการ:** `[mcupr_org field="name|alt|address|tel|email"]` (ข้อมูลหน่วยงานจาก Customizer), `[mcupr_contact]` (ที่อยู่/โทร/อีเมลเป็นการ์ด), `[mcupr_sitemap]` (แผนผังเว็บไซต์อัตโนมัติ)

## เลย์เอาต์เมนู (v2): แคปซูลลอย · การ์ดไซด์บาร์ + กรอบเนื้อหา

- **เมนูบน (Top):** โลโก้/ชื่อ, เมนูหลัก และปุ่มเครื่องมือเป็น **แคปซูลลอย 3 ก้อนแยกกัน** (มีแถบดำเมนูรอง นักศึกษา/บุคลากร/ศิษย์เก่า ด้านบนเหมือนเดิม)
- **เมนูข้าง (Sidebar) / ผสม (Hybrid):** ไม่มีแถบดำ — ลิงก์เมนูรอง (นักศึกษา บุคลากร ศิษย์เก่า…) ย้ายไปอยู่ในแคปซูลหัวเว็บด้านขวาบน; **ไซด์บาร์ซ้ายเป็นเมนูหลัก** ในการ์ดใบเดียวที่สูงเท่าเมนู (ไม่ยืดยาวเต็มจอ) โลโก้อยู่บนสุดของการ์ด ปุ่มยุบ/ขยายอยู่ล่างสุด; ฝั่งเนื้อหาอยู่ในกรอบมนเดียว (`#page`) ที่ขอบบนเสมอกับการ์ดไซด์บาร์
- **Sidebar:** กาง (ตรึงอยู่ ดันเนื้อหา) หรือยุบเป็นไอคอนกลม — รายการปัจจุบันเป็นวงกลมสีหลักในการ์ด; **ไม่มีการกางเมื่อเอาเมาส์ชี้แล้ว** — กดปุ่ม ยุบ/ขยาย ที่เป็นการ์ดแยกติดมุมซ้ายล่าง (เหมือนปุ่มเปิดเมนูบนมือถือ); ไอคอนที่ยุบมี tooltip บอกชื่อเมนู. **Hybrid:** เริ่มต้นเป็นไอคอน แต่กดปุ่มขยายได้ และจำค่าไว้
- ลูกศรเปิดเมนูย่อยเป็นปุ่มกลมขนาด 2.5rem มีระยะห่างจากขอบ; บนมือถือ/แท็บเล็ต (<1100px) ใช้ลิ้นชักเมนูเหมือนเดิม
- **ปุ่มแชร์:** ข่าว/บทความมีปุ่ม Facebook และ LINE (สีแบรนด์ ผ่าน AA) ทั้งด้านบนและแถบ “แชร์เรื่องนี้” ท้ายบทความ — ไม่มีเครือข่ายอื่น

## เครื่องมือเนื้อหา (v1.7): ผลงาน · ไฟล์แนบ · ยอดผู้ชม · ผังบริหาร · Hero

ทุกเมนูในหลังบ้านและตัวปรับแต่งของธีมแสดงเป็น **ภาษาไทย** (พจนานุกรมอยู่ใน `scripts/admin_th.py` → รัน `python3 scripts/make-admin-th.py`; `tests/check.sh` ตรวจว่าทุกข้อความมีคำแปลไทย; ปิดได้ด้วย `add_filter( 'mcupr_admin_thai', '__return_false' )`)
- **ผลงานและรางวัล** (เมนู “ผลงานและรางวัล”, หน้ารวม `/works/`): ผลงานที่นำไปแข่งขัน/ประกวด แยกจากข่าวโดยสิ้นเชิง — มี **หมวดหมู่ของตัวเอง** (`/work-category/…`) ไม่ปนกับหมวดข่าว; กรอกชื่อรายการแข่งขัน รางวัล ปี (ค.ศ. แสดง พ.ศ.) หน่วยงานผู้จัด ทีม ลิงก์ ภาพปก; กรองตามหมวดและปี; `[mcupr_works count="6" category="slug"]`
- **ไฟล์แนบทุกโพสต์** (ข่าว หน้าเพจ กิจกรรม ผลงาน): กล่อง “ไฟล์แนบ” เลือกรูป/PDF/เอกสารจากคลังสื่อ ตั้งชื่อที่แสดง ข้อความขนาดไฟล์ (เว้นว่าง = คำนวณเอง) **จำนวนดาวน์โหลดสูงสุด** (0 = ไม่จำกัด) และแก้ **ยอดดาวน์โหลด** ได้; ผู้เข้าชมเห็นประเภทไฟล์ ขนาด ยอดดาวน์โหลด และจำนวนที่เหลือ; ลิงก์ดาวน์โหลดนับยอดและบังคับขีดจำกัดที่เซิร์ฟเวอร์ (ครบแล้วขึ้น 403)
- **ยอดผู้เข้าชม** ทุกโพสต์: นับอัตโนมัติ (คนเดิมนับครั้งเดียวต่อ 6 ชั่วโมง, ไม่นับผู้แก้ไขเว็บ/บอต) แก้ตัวเลขได้ในกล่อง “จำนวนผู้เข้าชม” และมีคอลัมน์ “เข้าชม” ในรายการโพสต์; ปิดการแสดงที่ Customizer → แอนิเมชัน ข่าว และการอ่าน (ใช้คุกกี้ `mcupr_seen` ซึ่งระบุไว้ในหน้านโยบายคุกกี้ของไฟล์เริ่มต้นแล้ว)
- **ผังการบริหารงาน** (เมนู “ผังการบริหารงาน”): เพิ่มหน่วยงาน/ตำแหน่ง ใส่ผู้ดำรงตำแหน่ง ลิงก์ รูป และชื่อหลายภาษา แล้ว **เลือก “หน่วยงานแม่” + “ลำดับ”** เพื่อโยงเป็นขั้นการบริหาร; แสดงด้วย `[mcupr_orgchart]` (หรือ `root="ID"` เพื่อเริ่มจากหน่วยงานหนึ่ง) — เดสก์ท็อปเป็นผังต้นไม้ มือถือเป็นรายการซ้อน
- **Hero หน้าแรก** (Customizer → MCUPR: หน้าแรก – Hero และแบนเนอร์): ภาพ, บรรทัดเล็ก, หัวข้อ 2 บรรทัด, ข้อความสั้น, ปุ่ม 2 ปุ่ม (ข้อความ+ลิงก์), ความเข้มของชั้นทับภาพ, ความสูง 4 ระดับ, ชิดซ้าย/กลาง, ส่วนของภาพที่คงไว้ และเปิด/ปิดปุ่มลิงก์ด่วน — ทุกข้อความแยก 4 ภาษา
- **เครดิตผู้จัดทำในฟุตเตอร์**: การ์ดมีรูป(หรือตัวอักษรแรก) ชื่อ ตำแหน่ง คำอธิบายสั้น อีเมล โทรศัพท์ และลิงก์ — กรอกที่ Customizer → ข้อมูลหน่วยงานและภาษา (“ผู้จัดทำเว็บไซต์: …”)

## ชุดเครื่องมือเพิ่มเติม (v1.8)

- **แถบประกาศ / ไว้อาลัย** (Customizer → MCUPR: แถบประกาศ): เปิด/ปิด, ข้อความ 4 ภาษา, ลิงก์, ช่วงวันที่แสดงอัตโนมัติ (ค.ศ. `ปปปป-ดด-วว`), 3 แบบ — ประกาศทั่วไป / เร่งด่วน (เหลืองอำพัน) / ไว้อาลัย (แถบดำพร้อมริบบิ้น และเลือกให้ทั้งเว็บเป็นขาว-ดำได้)
- **Hero แบบสไลด์** (สูงสุด 3 สไลด์): สไลด์ 1 = Hero เดิม, สไลด์ 2–3 ตั้งภาพ/หัวข้อ/ข้อความ/ปุ่มที่ Customizer; ปุ่มก่อนหน้า-ถัดไป จุดเลือกสไลด์; **เปลี่ยนอัตโนมัติปิดอยู่เป็นค่าเริ่มต้น** (เปิดได้ ทุก 7 วินาที พร้อมปุ่มหยุด และหยุดเองเมื่อปิดแอนิเมชัน/ผู้ใช้ตั้ง reduced-motion); ไม่มี JavaScript จะเห็นสไลด์แรก
- **ศูนย์เอกสารดาวน์โหลด** `[mcupr_documents per_page="20"]`: รวมไฟล์แนบของทุกโพสต์ ค้นหาและกรองตามประเภท (PDF/Word/Excel/PowerPoint/รูป/อื่นๆ) ตารางที่เป็นการ์ดบนมือถือ — เหมาะกับ ITA จัดซื้อจัดจ้าง แบบฟอร์ม
- **แบบฟอร์มติดต่อ / ร้องเรียน** `[mcupr_form type="contact"]`, `[mcupr_form type="complaint"]` (ไม่ต้องใช้ปลั๊กอิน, ทำงานได้โดยไม่มี JavaScript): ช่องข้อมูลมีป้ายกำกับ, ติ๊กยินยอม PDPA, กันสแปมด้วยช่องดักบอต + เวลากรอกขั้นต่ำ 3 วินาที + โทเค็นเซ็นชื่อ + จำกัด 5 ข้อความ/ชั่วโมง; ทุกข้อความได้ **เลขที่รับเรื่อง** (MC-วันที่-เลข), บันทึกในเมนู “ข้อความจากแบบฟอร์ม” และส่งอีเมลถึงที่อยู่ที่ตั้งใน Customizer (ว่าง = อีเมลผู้ดูแลเว็บ)
- **บุคลากรและผู้บริหาร** (เมนูในหลังบ้าน): ชื่อ ตำแหน่ง สังกัด รูป อีเมล โทรศัพท์ ชื่อ/ตำแหน่งหลายภาษา แยกกลุ่ม (ผู้บริหาร/อาจารย์/เจ้าหน้าที่) จัดลำดับ; แสดงด้วย `[mcupr_people group="executives" columns="3"]`
- **สถิติเว็บไซต์** (Dashboard → สถิติเว็บไซต์ และวิดเจ็ตหน้า Dashboard): ยอดวันนี้/7/30 วัน/ทั้งหมด กราฟรายวัน หน้าที่คนเข้ามากที่สุด และไฟล์ที่ดาวน์โหลดมากที่สุด — นับโดยธีมเอง ไม่มีสคริปต์ติดตามภายนอก
- **ไอคอนโซเชียลในฟุตเตอร์**: Facebook, YouTube, LINE OA, Instagram, X, TikTok (แสดงเฉพาะที่ใส่ลิงก์ใน Customizer)

## ปฏิทินกิจกรรม (ในธีม ไม่ต้องใช้ปลั๊กอิน)

เมนู **กิจกรรม** ในหลังบ้าน (`mcupr_event`, หน้ารวม `/events/`): ใส่ชื่อ เนื้อหา ภาพ และกล่อง *Event details* (วัน-เวลาเริ่ม/สิ้นสุด, ตลอดวัน, สถานที่, ลิงก์ลงทะเบียน) — แปล EN/中文/日本語 ได้ในกล่อง Translations เดิม
- **ปฏิทินรายเดือน** (ปี พ.ศ. ในภาษาไทย, วันอาทิตย์เป็นวันแรก, เลื่อนเดือนด้วยลิงก์ธรรมดา `?ev_m=YYYY-MM` — ไม่ใช้ JavaScript) + รายการกิจกรรมของเดือนและที่กำลังจะมาถึง; บนมือถือแสดงจุดขีดเส้นใต้ที่วันที่มีกิจกรรมและรายการด้านล่าง
- **Shortcode:** `[mcupr_calendar]` (ปฏิทิน), `[mcupr_events count="4"]` (กิจกรรมที่จะมาถึง — ใส่ในหน้าแรกผ่าน Customizer → Shortcodes ได้)
- **หน้ากิจกรรม:** วัน-เวลา/สถานที่, ปุ่มลงทะเบียน, เพิ่มลง Google Calendar, ดาวน์โหลด `.ics`; ฟีดสมัครรับทุกกิจกรรม `/?mcupr_ics=all`; ข้อมูลโครงสร้าง schema.org/Event สำหรับ Google
- ข้อมูลกิจกรรมอยู่ในฐานข้อมูล ถ้าเปลี่ยนธีมเมนูจะหายไปแต่ข้อมูลไม่หาย ไฟล์เริ่มต้นมีหน้า “ปฏิทินกิจกรรม” (อยู่ใต้เมนูข่าวสาร) และกิจกรรมตัวอย่าง 3 รายการ (วันที่นับจากวันที่สร้างไฟล์ — แก้หรือลบหลังนำเข้า)

## ไฟล์เริ่มต้น (Starter import): เมนู + หน้าแบบเว็บไซต์ราชการ

`mcupr/starter/mcupr-starter.xml` — นำเข้าครั้งเดียวได้ **55 หน้า + กิจกรรมตัวอย่าง 3 รายการ** (เกี่ยวกับ, การศึกษา, วิจัย, นักศึกษา, ธรรมาภิบาล/ITA/OIC/ข้อมูลเปิด/จัดซื้อจัดจ้าง/ร้องเรียน/ป้องกันทุจริต, นโยบายความเป็นส่วนตัว (PDPA), คุกกี้, แถลงการณ์การเข้าถึง, ความปลอดภัย, ข้อกำหนดการใช้งาน, แผนผังเว็บไซต์, FAQ, ติดต่อ, e-Service), **3 หมวดข่าว** และ **7 เมนู** (เมนูหลัก 4 ภาษา พร้อม mega menu + ไอคอน, ลิงก์ท้ายเว็บ 4 คอลัมน์, ลิงก์ด่วน, แถบยูทิลิตี้) ที่ผูกเข้าตำแหน่งเมนูให้อัตโนมัติ

1. ติดตั้งและเปิดใช้ธีม → Tools → Import → *WordPress* (ติดตั้งปลั๊กอิน WordPress Importer ชั่วคราวเมื่อระบบถาม) → เลือกไฟล์ → *Assign posts to an existing user* → Submit
2. หน้าทุกหน้ามีกล่อง **โครงร่างหน้า (Draft)** และข้อความ `[ ]` ให้แก้เป็นข้อมูลจริง — ค้นหา `mcupr-todo` เพื่อดูว่าเหลือหน้าไหน; เนื้อหานโยบาย (PDPA/คุกกี้/ความปลอดภัย) เป็นแม่แบบ **ต้องให้ฝ่ายกฎหมาย/DPO ตรวจก่อนเผยแพร่**
3. ชื่อหน้าแปลครบ 4 ภาษา (เมนูแต่ละภาษามีป้ายของตัวเอง); ตั้งค่า Settings → Reading → หน้าแรกเป็นหน้าแบบคงที่ได้ตามต้องการ — ลิงก์ท้ายเว็บใช้ slug (`privacy-policy`, `cookie-policy`, `accessibility-statement`, `sitemap`, `contact`) จึงทำงานโดยไม่ต้องตั้ง Customizer
4. นำเข้า **ครั้งเดียว** — นำเข้าซ้ำจะไม่ซ้ำหน้า แต่จะซ้ำรายการเมนู
5. สร้างไฟล์ใหม่หลังแก้เนื้อหา: แก้ `scripts/starter_content.py` แล้วรัน `python3 scripts/make-starter.py`; ทดสอบด้วย `cd tests && bash starter.sh` (นำเข้าจริงด้วย WordPress Importer + ตรวจเมนู/หน้า/axe ทุกชนิดหน้า)

### คะแนน PageSpeed
ธีมโหลดฟอนต์ woff2 เฉพาะตัวที่ใช้ (preload ตัวเดียว), SweetAlert2 โหลดเมื่อต้องใช้เท่านั้น, แบนเนอร์คุกกี้เป็น HTML ล้วน, ภาพมี width/height + lazy/`fetchpriority`, ไม่โหลด emoji/embed — ทดสอบ Lighthouse มือถือ (4G จำลอง) ได้ Performance 99, Accessibility / Best Practices / SEO 100 ในสภาพแวดล้อมทดสอบ **คะแนนจริงบนโฮสต์ขึ้นกับเซิร์ฟเวอร์** (TTFB, การบีบอัด gzip/brotli, HTTP/2, แคชหน้า, ขนาดรูปที่อัปโหลด) — แนะนำเปิดแคชหน้าและบีบอัดที่เซิร์ฟเวอร์ และอัปโหลดรูปภาพเป็น WebP/ขนาดไม่เกินที่แสดงจริง

## แนวทางตามมาตรฐานเว็บไซต์ภาครัฐ / การเข้าถึง

อ้างอิง **WCAG 2.2 ระดับ AA** (เวอร์ชันล่าสุดของ W3C) ซึ่งเป็นฐานของมาตรฐานเว็บไซต์ภาครัฐของ DGA และ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

- Skip links 3 จุด (เนื้อหา/เมนู/ท้ายเว็บ), landmarks (`header`, `nav`, `main`, `footer`, `role=search`), ลำดับหัวข้อถูกต้อง, breadcrumb
- `lang` ของหน้าและของส่วนที่ต่างภาษา, `hreflang`
- โฟกัสมองเห็นชัด 3px (2.4.7, 2.4.11, 2.4.13), ใช้งานด้วยคีย์บอร์ดได้ทั้งหมด (เมนูย่อยมีปุ่มสลับ, `Esc` ปิด), ไม่มี keyboard trap
- ขนาดเป้าหมายแตะ/คลิก ≥ 44px (2.5.8), คอนทราสต์ข้อความ ≥ 4.5:1 ทั้งโหมดสว่าง/มืด
- แจ้งการเปลี่ยนค่าผ่าน `aria-live`, เคารพ `prefers-reduced-motion`
- ท้ายเว็บไซต์มีลิงก์ นโยบายคุ้มครองข้อมูลส่วนบุคคล, นโยบายคุกกี้, นโยบายการเข้าถึง, แผนผังเว็บไซต์, ติดต่อเรา (ตั้งค่าที่ Customizer → *MCUPR: Policy pages*) และการแจ้งคุกกี้ตาม PDPA ด้วย SweetAlert2 (ใช้เฉพาะคุกกี้ที่จำเป็น)
- ไม่โหลดฟอนต์/สคริปต์จากภายนอก (ไม่มีการส่ง IP ไปบุคคลที่สาม) — ใช้ฟอนต์ระบบ (Sarabun/Noto Sans Thai หากมีในเครื่อง); ต้องการฝังฟอนต์ให้เพิ่ม `@font-face` ของไฟล์ที่โฮสต์เอง

> ธีมช่วยให้ผ่านเกณฑ์ด้านโครงสร้างและการแสดงผล แต่การรับรองตามมาตรฐานต้องตรวจสอบเนื้อหาจริง (alt รูปภาพ, ตาราง, PDF, วิดีโอมีคำบรรยาย ฯลฯ) ด้วย เช่น axe / WAVE และการทดสอบกับ screen reader (NVDA, VoiceOver)

## v1.10.0: พิมพ์ A4 พร้อมหัว-ท้ายกระดาษแบบจดหมายข่าวราชการ

ปุ่ม “พิมพ์” ของข่าว/หน้าเพจพิมพ์เป็น **A4** (ไม่มีแถบเมนู ปุ่มแชร์ หรือเครื่องมืออ่านออกเสียง) โดยมี **หัวกระดาษและท้ายกระดาษซ้ำทุกแผ่น** และเว้นพื้นที่ตรงกลางให้เนื้อหาไหลต่อหลายหน้า (ทดสอบสร้าง PDF จริงจาก Chromium)

ตั้งค่าที่ Customizer → **MCUPR: Print on A4** (ไม่มีโค้ดให้แก้):
- **อัปโหลดกราฟิกหัวกระดาษ / ท้ายกระดาษ** (กว้างเต็มแผ่น 210 มม.) และ **ภาพพื้นหลังทั้งแผ่น** (เช่น ลายน้ำจาง) — ภาพพื้นหลังพิมพ์อยู่หลังตัวอักษร
- กำหนดความสูงหัว/ท้าย (มม.) และระยะขอบซ้ายขวาของเนื้อหา — เนื้อหาไม่ทับกราฟิก
- ถ้าไม่ใส่ภาพ จะใช้หัวกระดาษตัวอักษรอัตโนมัติ: ตราสัญลักษณ์ + ชื่อหน่วยงาน (ไทย/อังกฤษ) + เส้นคู่สีหลัก/สีเสริม และท้ายกระดาษเป็นที่อยู่หน่วยงาน (แก้ข้อความได้แยกตามภาษา)
- เลือกพิมพ์/ไม่พิมพ์: ที่อยู่เว็บ+วันที่ท้ายทุกแผ่น, บรรทัดหมวดหมู่/วันที่ใต้ชื่อเรื่อง, ภาพในบทความ (ประหยัดหมึก)
- รายข่าว/รายหน้า: กล่อง “Print on A4” ที่หน้าแก้ไข ติ๊กเพื่อพิมพ์แบบ A4 เปล่าไม่มีหัว-ท้าย
- ในกล่องพิมพ์ของเบราว์เซอร์ให้เปิด “กราฟิกพื้นหลัง” (Background graphics) เพื่อให้ภาพหัว-ท้ายออกครบ — เทคนิคนี้ทดสอบกับ Chromium/Edge/Chrome
- **โฟลเดอร์หมวดย่อย** เป็นสี่เหลี่ยมจัตุรัสขนาดเท่ากันทุกใบ ชื่อยาวตัดที่ 3 บรรทัด (ชี้เมาส์ดูชื่อเต็ม)
- **ไซด์บาร์ที่ยุบ** เป็นแคปซูลเต็มวง ปลายบน-ล่างเป็นครึ่งวงกลมสมบูรณ์ ไม่มีมุมโค้งที่ไม่มาชนกัน และปุ่มขยายเป็นวงกลมสมบูรณ์

**บัญชีเครื่องราชอิสริยาภรณ์ (แก้ไขได้ทั้งหมด)** — มาตรฐาน 16 ชั้น (ม.ป.ช. ม.ว.ม. ป.ช. ป.ม. ท.ช. ท.ม. ต.ช. ต.ม. จ.ช. จ.ม. บ.ช. บ.ม. และเหรียญทอง/เงิน ช้างเผือก/มงกุฎไทย) ปรับ ชื่อไทย/อังกฤษ อักษรย่อ ลำดับชั้น เปิด/ปิด เพิ่มรายการเอง และ **ภาพเหรียญ**: อัปโหลดภาพของจริงต่อชั้น หรือใช้เหรียญที่วาดให้พร้อมเลือกสีสายแพร 2 สีและสีโลหะ (สีเริ่มต้นเป็นตัวแทน ปรับให้ตรงของจริงได้) · คืนค่ามาตรฐานได้

## v1.14.0: นำเข้าบุคลากรจาก Excel / CSV

ที่ **ศูนย์บุคลากร → นำเข้าและส่งออก**: ดาวน์โหลดแม่แบบ (CSV มีตัวอย่าง 1 แถว) → กรอก → อัปโหลดไฟล์ `.xlsx` หรือ `.csv` → **ดูตัวอย่างก่อน** (ใหม่ / อัปเดตคนเดิม / ข้าม พร้อมเหตุผลรายแถว) → กดยืนยัน — ยังไม่เขียนอะไรจนกว่าจะยืนยัน
- หัวคอลัมน์เป็นไทยหรืออังกฤษ เรียงแบบไหนก็ได้ (20 คอลัมน์: ชื่อ-สกุล, ชื่ออังกฤษ, ตำแหน่ง, ตำแหน่งอังกฤษ, ตำแหน่งทางวิชาการ, ประเภทบุคลากร, หน่วยงาน, หัวหน้า, กลุ่ม, อีเมล, โทร, ที่ทำงาน, ลิงก์งานวิจัย, ความเชี่ยวชาญ, เครื่องราชฯ, ซ่อน, ไม่มีหน้าโปรไฟล์, ลำดับ, ภาพ (URL), ประวัติ) — จำเป็นแค่ “ชื่อ-สกุล”
- **หน่วยงาน** จับคู่ชื่อกับผังการบริหารอัตโนมัติ (ไม่พบ = เก็บเป็นข้อความ พร้อมคำเตือน); **กลุ่ม** สร้างให้ถ้ายังไม่มี; **เครื่องราชฯ** เขียนเช่น `ท.ช. 2562; ต.ม. 2557` (จับคู่กับบัญชีเครื่องราชฯ); **ซ่อน** เช่น `โทร, ที่ทำงาน`
- **จับคู่คนเดิม** ด้วยอีเมล (ถ้าไม่มีใช้ชื่อตรงตัว) → อัปเดต; ช่องว่างไม่ลบข้อมูลเดิม; เลือกได้ว่าไม่อัปเดตคนเดิม และคนใหม่ให้เผยแพร่หรือเป็นฉบับร่าง; ดาวน์โหลดภาพจากลิงก์ (ต้องติ๊กเอง)
- ไฟล์ CSV ภาษาไทยจาก Excel เก่า (Windows-874) แปลงให้อัตโนมัติ; ตัวคั่น , ; หรือ Tab; ไฟล์ .xlsx ต้องใช้ PHP zip (ถ้าไม่มี ให้บันทึกเป็น CSV) ไม่รองรับ .xls เก่า; สูงสุด 1,000 แถว / 2 MB
- **ส่งออกบุคลากรทั้งหมดเป็น CSV** (รูปแบบเดียวกับแม่แบบ แก้ใน Excel แล้วนำเข้าคืนได้) · เฉพาะผู้ใช้ที่แก้เพจได้ + nonce; เซลล์ที่ขึ้นต้นด้วย = + - @ ถูกป้องกันสูตรในไฟล์ส่งออก

## v1.15.0: ผังการบริหารงานแบบวิทยาเขต (กล่องข้าง · แผงรายการ · สีกล่อง)

ผังการบริหารรองรับโครงสร้างจริงแบบวิทยาเขตแพร่ — ที่หน้าแก้ไขหน่วยงาน (Administration chart) เลือก **“วาดเป็นแบบไหน”** และ **“สีกล่อง”**:
- **กล่องในสายการบังคับบัญชา** (ค่าเริ่มต้น) — ต่อกันด้วยเส้น; แถวเดียวกันขยายความกว้างตามจำนวนกล่องใต้มัน (เช่น ผู้ช่วยอธิการบดีฝ่ายวิชาการมีผู้อำนวยการ 3 หน่วยใต้เส้น) · เลื่อนอ่านบนมือถือเป็นรายการซ้อน
- **กล่องข้าง** — คณะกรรมการ / ที่ปรึกษา / อนุกรรมการ อยู่ข้างหน่วยงานด้านบน เชื่อมด้วยเส้นประ
- **รายการในแผง** — ส่วนงานและกลุ่มงาน แสดงเป็นหัวข้อพร้อมรายการ “– กลุ่มงาน…” ในแผงสีใต้กล่องผู้อำนวยการ (ลูกของหน่วยแบบนี้แสดงเป็นบรรทัดในแผง)
- **สีกล่อง** 10 สี (มะกอก ครีมทราย ฟ้าอ่อน ส้มพีช เขียวอ่อน เขียว ฟ้าน้ำทะเล ชมพู เทา สีหลักเว็บ) ตัวอักษรเลือกให้อ่านชัดทุกโหมด · อัตโนมัติ = ตามระดับ
- ชื่อตำแหน่งที่ซ้ำกับชื่อหน่วยไม่ถูกพิมพ์ซ้ำในกล่อง
- **ผังตัวอย่างในไฟล์ starter** เปลี่ยนเป็นโครงสร้างวิทยาเขตแพร่ (31 หน่วย): อธิการบดี → สภาวิทยาเขต → รองอธิการบดี (คณะกรรมการ/ที่ปรึกษา/อนุกรรมการ ข้างๆ) → ผู้ช่วยอธิการบดี 3 ฝ่าย → ผู้อำนวยการ 3 หน่วย (+วิทยาลัยสงฆ์นครลำปาง) พร้อมส่วนงาน/กลุ่มงาน — ชื่อผู้ดำรงตำแหน่งเป็นข้อความ [ชื่อ…] ให้แทนที่ หรือเชื่อมกับบุคลากรในศูนย์บุคลากร

## v1.16.0: กระดานสนทนา · คำถามที่พบบ่อย · อัลบั้มภาพ · โหวต/แบบสำรวจ

ทั้งหมดอยู่ในธีม ไม่ต้องใช้ปลั๊กอิน หลัง merge ให้เข้า **ตั้งค่า → ลิงก์ถาวร** แล้วกดบันทึกหนึ่งครั้ง (เพื่อให้ URL ใหม่ เช่น `/forum/topic/…`, `/albums/…` ใช้งานได้)

- **กระดานสนทนา** (`[mcupr_forum]`, หน้า `/forum/` ในไฟล์เริ่มต้น): กระทู้ = โพสต์ชนิด `mcupr_topic`, ห้อง = หมวด `mcupr_board`, คำตอบ = ความเห็นของ WordPress
  ตั้งค่าที่ *กระทู้ → ตั้งค่า*: ใครตั้งกระทู้/ตอบได้ (ทุกคน · ต้องเข้าสู่ระบบ), การตรวจก่อนแสดง (ทุกโพสต์ · เฉพาะผู้มาเยือน · ไม่ตรวจ), คำต้องห้าม, จำกัดจำนวนลิงก์, ปิดกระทู้เงียบอัตโนมัติ, แจ้งอีเมลผู้ดูแล
  กันสแปมด้วยช่องดัก + โทเคนเวลา + จำกัดความถี่ต่อผู้เยี่ยมชม (เก็บเฉพาะค่าแฮชของ IP) + ต้องยินยอม PDPA; ผู้เยี่ยมชมกด “รายงาน” ได้ ครบ 3 ครั้งซ่อนอัตโนมัติ; เจ้าหน้าที่ปักหมุด/ล็อกกระทู้ได้; อีเมลผู้โพสต์เห็นเฉพาะผู้ดูแล
- **คำถามที่พบบ่อย (FAQ)** (`[mcupr_faq]`, ตัวเลือก `category=` `open=all|first` `search=1`): โพสต์ชนิด `mcupr_faq` + หมวด, แปลหลายภาษาได้, มีช่องค้นหา, ใส่ข้อมูลโครงสร้าง FAQPage ให้ Google
- **อัลบั้มภาพ** (`/albums/`, `[mcupr_albums]`): เลือกรูปหลายรูปพร้อมกันและลากเรียง, คำบรรยายจากคลังสื่อ, ภาพเด่นเป็นปก; กดรูปเปิดแกลเลอรี (lightbox) ใช้คีย์บอร์ด ← → Esc, ปัดนิ้วบนมือถือ, โฟกัสวนอยู่ในกล่อง และกลับไปที่รูปเดิมเมื่อปิด
- **โหวต / แบบสำรวจความพึงพอใจ** (`[mcupr_poll id="…"]`): ตัวเลือกเดียว · หลายข้อ · ความพึงพอใจ 5 ระดับ, กำหนดวันปิด, เลือกแสดงผลได้ (หลังโหวต/เสมอ/ไม่แสดง), โหวตได้คนละครั้ง (คุกกี้ + ค่าแฮช IP เก็บ 30 วัน) นับเฉพาะจำนวนไม่ผูกกับตัวบุคคล; แก้ตัวเลือกแล้วคะแนนเก่าถูกล้าง

ทดสอบ: `tests/php/forum.php`, `faq.php`, `albums.php`, `polls.php` และบล็อกใน `tests/e2e/starter.js` (axe, มือถือ, คีย์บอร์ด, lightbox)

- ตัวเล่นเป็นภาพปกพร้อมปุ่มเล่น: **ไม่โหลดอะไรจาก YouTube/Vimeo และไม่ตั้งคุกกี้จนกว่าผู้เข้าชมจะกดเล่น** (เป็นมิตรกับ PDPA) YouTube เล่นจาก youtube-nocookie.com, Vimeo ใส่ `dnt=1`; ใช้คีย์บอร์ดได้ มีชื่อวิดีโอสำหรับโปรแกรมอ่านหน้าจอ
- ภาพปก: ภาพเด่นที่ตั้งเอง ถ้าไม่ตั้งและเป็น YouTube ระบบดึงภาพปกให้ครั้งเดียวตอนบันทึก (ฝั่งเซิร์ฟเวอร์ ไม่ใช่ฝั่งผู้เข้าชม)
- ลิงก์ที่ไม่รู้จัก (ไม่ใช่ YouTube / Vimeo / .mp4) ไม่ถูกบันทึกและไม่ถูกแสดง
- กล่อง “Video from another site” ในหน้าแก้ไข **ข่าว** — ใส่ลิงก์แล้วตัวเล่นขึ้นต้นบทความทุกเลย์เอาต์
- วางลิงก์ YouTube/Vimeo ไว้บรรทัดเดียวในตัวแก้ไขใดก็ได้ จะได้ตัวเล่นแบบเดียวกัน
- shortcode: `[mcupr_video url="https://youtu.be/…"]`, `[mcupr_videos count="6" category="slug"]`

**การ์ดข่าว**: ทุกการ์ดในแถวสูงเท่ากัน, คำนำตัดที่ 3 บรรทัด (การ์ดเด่น 6), ชื่อข่าวไม่เกิน 3–4 บรรทัด, ป้ายหมวดเป็นแคปซูล, ท้ายการ์ดมี “อ่านต่อ →”; ภาพโปสเตอร์/ภาพแนวตั้งหรือแคบมากแสดงเต็มภาพบนฉากหลังเบลอของภาพเดียวกัน (ไม่ถูกครอปจนอ่านไม่ออก) ภาพแนวนอนปกติครอปเต็มกรอบเหมือนเดิม

## v1.18.0: จัดหน้าหลักใหม่ · หน้าต้อนรับ · โหมดปิดปรับปรุง · ไว้อาลัย

**หน้าหลัก** (ปรับแต่ง → *MCUPR: ส่วนต่างๆ ของหน้าแรก*): เลือกเปิด/ปิดแต่ละส่วนได้ — แนะนำหน่วยงาน, สไลด์ข่าวเด่น, กิจกรรมที่กำลังจะมาถึง, วิดีโอ+อัลบั้มล่าสุด, ข่าวแยกหมวด, มาหาเรา (ภาพหลักและลิงก์ด่วนแสดงเสมอ) ส่วนใหม่ “กิจกรรม + วิดีโอล่าสุด” อยู่คู่กัน และ “อัลบั้มภาพ” 4 อัลบั้มล่าสุด จะแสดงเฉพาะเมื่อมีข้อมูล **ค่าเริ่มต้นเปลี่ยน:** “ข่าวแยกตามหมวด” ปิดไว้ (ซ้ำกับตารางข่าว) เปิดได้ที่เดิม

เมนู **หน้าต้อนรับและปิดปรับปรุง** ในผู้ดูแลระบบ (เฉพาะผู้ดูแลระบบ):
- **โหมดปิดปรับปรุง**: ผู้เข้าชมเห็นหน้า “กลับมาเร็วๆ นี้” (HTTP 503 + Retry-After + noindex; feed/REST ปิด) ผู้ดูแลที่เข้าสู่ระบบเห็นเว็บจริงและมีแถบเตือน; มีลิงก์ลับสำหรับผู้ตรวจ (เห็นเว็บจริง 12 ชม.) และรายการ IP ที่ให้ผ่าน; ข้อความ 4 ภาษา รูป และเวลาที่คาดว่าจะกลับมา
- **หน้าต้อนรับ** ตามโอกาสพิเศษ: ชุดโอกาส (วโรกาสสำคัญ, ปีใหม่, สงกรานต์, วันครบรอบ, รับปริญญา, ไว้อาลัย, กำหนดเอง) กำหนดสีและข้อความตั้งต้น; รูปพื้นหลัง; ข้อความ/ปุ่ม 4 ภาษา; ช่วงวันที่เริ่ม–สิ้นสุด; ความถี่ที่แสดง (กี่วัน/ทุกครั้งที่เปิดเบราว์เซอร์); เข้าเว็บอัตโนมัติพร้อมตัวนับถอยหลังและปุ่มหยุด (WCAG 2.2.1) แสดงเฉพาะหน้าแรก ครั้งแรกของผู้เข้าชม (ใช้คุกกี้ที่จำเป็น `mcupr_welcome`) ไม่แสดงให้บอตค้นหาและผู้ดูแล (ดูตัวอย่างได้ที่ปุ่ม “ดูตัวอย่าง”)
- **ไว้อาลัย**: เว็บไซต์ทั้งหมดเป็นขาวดำตามช่วงวันที่ที่กำหนด

ทดสอบ: `tests/php/site-status.php` (การบันทึก, ใครเห็นอะไร, คุกกี้, ชุดโอกาสอ่านออกได้ทุกชุด) และบล็อกใน `tests/e2e/starter.js` (503/Retry-After/REST, ลิงก์ผู้ตรวจ, หน้าต้อนรับ, บอต, นับถอยหลัง, ขาวดำ, axe)

## v1.20.0: นำเข้าและซิงค์ปฏิทินกิจกรรม (.ics)

เมนู **MCUPR → นำเข้าและซิงค์ปฏิทิน**:
1. **นำเข้าไฟล์ .ics** (ส่งออกจาก Google Calendar / Outlook / Apple Calendar ฯลฯ) — นำเข้าซ้ำไม่สร้างซ้ำ (จับคู่ด้วย UID) เลือกเผยแพร่ทันทีหรือเป็นฉบับร่างเพื่อตรวจก่อน
2. **ซิงค์กับที่อยู่ปฏิทิน** (เช่น “ที่อยู่ลับในรูปแบบ iCal” ของ Google Calendar, `webcal://`) — อ่านซ้ำอัตโนมัติทุกชั่วโมง / วันละสองครั้ง / วันละครั้ง (WP-Cron) หรือกด “ซิงค์เดี๋ยวนี้”; ตัวเลือกลบกิจกรรมที่หายจากต้นทาง; ดึงผ่าน `wp_safe_remote_get` (ไม่รับที่อยู่ภายใน/เครือข่ายส่วนตัว) ขนาดไม่เกิน 2 MB
3. ทางกลับกัน: ที่อยู่ติดตามปฏิทินของเว็บไซต์ (`/?mcupr_ics=all`) ที่มีอยู่เดิม แสดงไว้ในหน้าเดียวกัน

รองรับ: เขตเวลา (TZID/UTC/ลอย → เขตเวลาของเว็บ), กิจกรรมทั้งวัน, DURATION, กิจกรรมซ้ำ (รายวัน รายสัปดาห์+วัน รายเดือน รายปี, COUNT/UNTIL/INTERVAL, EXDATE, ไม่เกิน 300 ครั้ง), ถูกยกเลิก (CANCELLED → ย้ายถังขยะ), ข้ามกิจกรรมที่จบไปเกิน 30 วัน; กิจกรรมที่นำเข้ามีกล่อง “ไม่ต้องเขียนทับสิ่งที่ฉันแก้ไข” ข้อจำกัด: กฎซ้ำที่ซับซ้อน (BYSETPOS, รายเดือนแบบ “วันจันทร์แรก”) แสดงเฉพาะครั้งแรก

- เข้าถึงได้: label/legend ผูกกับช่อง, ข้อความช่วยเหลือเชื่อมด้วย aria-describedby, สรุปข้อผิดพลาดพร้อมลิงก์ไปยังช่อง, ค่าที่กรอกไว้ไม่หายเมื่อมีข้อผิดพลาด

**ไฟล์ import เฉพาะของใหม่**: `mcupr/starter/mcupr-starter-addons.xml` (สร้างด้วย `python3 scripts/make-starter.py --addons`) สำหรับเว็บที่เคย import ไฟล์เริ่มต้นเดิมแล้ว — มีเฉพาะหน้าใหม่ (เอกสารดาวน์โหลด, ปฏิทินกิจกรรม, กระดานสนทนา, ตัวอย่างหน้าต้อนรับ, แบบสอบถามภายใน, แบบสำรวจความพึงพอใจ) และตัวอย่างของฟังก์ชัน (กิจกรรม, ผลงาน, ผังบริหาร, FAQ, บุคลากร, กระดานย่อย, ฟอร์ม, โหวต) **ไม่มีเมนูและไม่แตะหน้าเก่า**: WordPress Importer ข้ามรายการที่ชื่อและวันที่ซ้ำกับของเดิม จึงไม่ทับหน้าที่แก้ไว้และ import ซ้ำก็ไม่ซ้ำ (ทดสอบด้วยตัว Importer จริง) เมนูใหม่ให้เพิ่มเองที่ ลักษณะที่ปรากฏ → เมนู

**ตรวจทุกหน้าทุกขนาดจอ** (`tests/e2e/audit.js`): ทุกที่อยู่สาธารณะของเว็บตัวอย่าง (112 ที่อยู่) × 7 ขนาด/รูปแบบเมนู (1920, 1366 บน/ข้าง, 1024, 768, 390, 320) ตรวจ: ตอบ 200, ไม่มี JS error, ไม่เลื่อนข้าง, ไม่มีองค์ประกอบล้นจอ, ไม่มีรูปเสีย, มี h1 หนึ่งอัน และผ่าน axe (WCAG 2.2 AA) — จากการตรวจนี้แก้: หัวข้อการ์ดอัลบั้ม/วิดีโอข้ามระดับ, ลิงก์ในข้อความ (ความเห็น, กระดานสนทนา) ไม่มีขีดเส้นใต้

**เปลี่ยนเส้นทาง & สถิติ** (MCUPR → เปลี่ยนเส้นทาง & สถิติ): ย้ายหน้าแล้วไม่ให้ลิงก์เก่าเสีย โดยไม่ต้องใช้ปลั๊กอิน
- เปลี่ยนเส้นทาง 301/302: ใส่พาธเดิม → ที่อยู่ใหม่ (ลงท้าย `*` ครอบคลุมทั้งหมวด และใช้ `{rest}` ต่อท้ายได้); ไม่สนตัวพิมพ์ใหญ่เล็ก/query string; ทำงานเฉพาะเมื่อหน้านั้นไม่พบ (จึงไม่ไปทับหน้าที่มีอยู่จริง); กันวนซ้ำ/ที่อยู่แบบ `javascript:`; นับจำนวนครั้งที่ใช้
- หน้าที่ไม่พบ (404): เก็บเฉพาะที่อยู่กับตัวนับ (ไม่เก็บ IP/ข้อมูลผู้เข้าชม, ข้ามบอท/ไฟล์รูป/สคริปต์, สูงสุด 300) กด "สร้างการเปลี่ยนเส้นทาง" จากรายการได้ทันที

## v1.27.0: รูปที่อัปโหลดถูกแปลงเป็น WebP อัตโนมัติ (MCUPR → รูปภาพ (WebP))

ช่วยคะแนนความเร็วมากที่สุด โดยไม่ต้องใช้ปลั๊กอินหรือไพทอน:

## v1.30.2: หน้าควบคุมของธีม (MCUPR → ภาพรวม) ออกแบบใหม่

- **แบนเนอร์** ชื่อธีม + เวอร์ชัน + ปุ่ม “เปิดเว็บไซต์”
- **สถานะตอนนี้:** ชิปบอกว่าโหมดปิดปรับปรุง / หน้าต้อนรับ / ไว้อาลัย เปิดอยู่หรือไม่ (สีเดียวกับปุ่มอินโฟของหน้าเว็บ: ส้ม / น้ำเงิน / ดำ) และจำนวนที่รอตรวจในกระดานสนทนา กดไปหน้าตั้งค่าได้ — “รอให้คุณดำเนินการ” ยังแจ้งกระดานที่รออนุมัติ
- **ทางลัด:** เขียนข่าว เพิ่มกิจกรรม เพิ่มอัลบั้ม เพิ่มหน้า อัปโหลดรูป แก้หน้าแรก (เปิด Customizer ที่ส่วนหน้าแรกเลย) — แสดงเฉพาะที่ผู้ใช้มีสิทธิ์
- **การ์ดทุกหมวด** (เนื้อหา / ผู้เข้าชม / บุคลากร + หน่วยงาน) มีไอคอนวงกลม สีประจำหมวด จำนวนรายการ และปุ่ม “+” เพิ่มใหม่ ความสูงเท่ากันทุกแถว
- **เครื่องมือและการตั้งค่า** (เฉพาะผู้ที่มีสิทธิ์): ตัวเลือกธีม บล็อกหน้าแรก หน้าต้อนรับและปิดปรับปรุง นำเข้า/ส่งออก ตรวจความเร็ว รูปภาพ (WebP) เปลี่ยนเส้นทางและสถิติ
- **ผู้ดูแลหน่วยงาน** เห็นการ์ด “หน่วยงานของคุณ” (เปิดเว็บ / แก้ไข) และทางลัดเขียนเท่านั้น — ไม่เห็นเครื่องมือ โหมดของเว็บ และจำนวนทั้งหมด
- ใช้ได้บนมือถือ (การ์ดเรียงคอลัมน์เดียว) ไม่ล้นจอที่ 1366–320 px ผ่าน axe
- เทสต์: `tests/php/admin-overview.php` (ผู้ดูแลระบบ ผู้ดูแลหน่วยงาน ผู้เข้าชม ชิปสถานะ) และ e2e (ขนาดจอ ความสูงการ์ด axe) — แก้เทสต์เมนูแอดมินเดิมที่นับการ์ดแบบเก่า

**2. นำเข้าเป็นชุด CSV (✅)** — MCUPR → นำเข้านิสิต: อัปโหลด CSV (Excel “CSV UTF-8”, ไฟล์ Thai Windows TIS-620/Windows-874 ก็อ่านได้ แม้เซิร์ฟเวอร์ไม่มี iconv) → รู้จักหัวคอลัมน์ไทย/อังกฤษเรียงอย่างไรก็ได้ → **หน้าตรวจก่อนนำเข้า** (ใหม่/อัปเดต/ผิดพลาดพร้อมเลขแถวและเหตุผล/คำเตือน) → นำเข้าเป็นก้อนละ 250 แถว หน้าเดินต่อเอง (หลายพันคนไม่หมดเวลา, สูงสุด 20,000 แถว/ไฟล์) → รายงาน + ดาวน์โหลดแถวที่ไม่ผ่านเป็น CSV; 3 โหมด (เพิ่ม+อัปเดต / เพิ่มอย่างเดียว / อัปเดตอย่างเดียว; ช่องว่างในไฟล์ไม่ทับข้อมูลเดิม); ตรวจรหัสซ้ำในไฟล์; ดาวน์โหลดแม่แบบ CSV, ส่งออกนิสิตทั้งหมด (กันสูตรสเปรดชีต), ไฟล์ตัวอย่าง 60 คนสมมติ (รหัสขึ้นต้น 99), บันทึกประวัติการนำเข้า

**3. บัญชีและพอร์ทัลนิสิต `/student/` (✅)** — บทบาท “นิสิต (บัญชีเข้าสู่ระบบ)” ที่ทำได้แค่ read, สร้างจากข้อมูลนิสิต (ชื่อผู้ใช้ = รหัสนิสิต) **ไม่มีใครเห็นรหัสผ่านเลย**: นิสิตตั้งรหัสเองผ่านลิงก์ที่ส่งไปยังอีเมลในข้อมูล (ไทย+อังกฤษในฉบับเดียว), เข้าสู่ระบบด้วยรหัสนิสิตหรืออีเมล (จำกัดจำนวนครั้ง), “ครั้งแรก/ลืมรหัสผ่าน” ตอบเหมือนกันเสมอ (ไม่เปิดเผยว่าใครเป็นนิสิต), หน้าส่วนตัว: ข้อมูลของตัวเอง + เนื้อหาเฉพาะนิสิต + เปลี่ยนรหัสผ่าน; นิสิตไม่เห็นแถบแอดมินและเข้า wp-admin ไม่ได้; ตั้งค่าที่ MCUPR → ตั้งค่าพอร์ทัลนิสิต

**4. เนื้อหาเฉพาะนิสิต (✅)** — ข่าว หน้า กิจกรรม ผลงาน อัลบั้ม วิดีโอ มีกล่อง “ใครดูได้”: ทุกคน / **นิสิตเท่านั้น** (เข้าสู่ระบบและสถานะ “กำลังศึกษา”) เลือกจำกัดเฉพาะบางระดับได้ → ซ่อนจากหน้าแรก รายการข่าว ค้นหา RSS sitemap REST API ลิงก์ก่อนหน้า/ถัดไป และรายการหน้า; ผู้เข้าชมที่ยังไม่ล็อกอินถูกพาไปหน้าเข้าสู่ระบบแล้วกลับมาหน้าเดิม, คนที่ล็อกอินแต่ไม่ใช่นิสิตเห็นหน้า “เฉพาะนิสิต” (403); ไฟล์แนบ (ดาวน์โหลดผ่านธีม) ใช้กฎเดียวกัน; ผู้สำเร็จการศึกษา/ลาออกเสียสิทธิ์โดยอัตโนมัติเมื่อเปลี่ยนสถานะ

**5. บทบาท “เจ้าหน้าที่ทะเบียน” (✅)** — จัดการนิสิตได้โดยไม่ต้องเป็นผู้ดูแลระบบ (ไม่เขียนข่าว ไม่ตั้งค่าเว็บ); ข้อมูลนิสิตรวมอยู่ในเครื่องมือส่งออก/ลบข้อมูลส่วนบุคคลของ WordPress (PDPA)

**เสนอไว้ (⏳ ยังไม่ได้ทำ):** ตารางเรียน/ผลการเรียน (นำเข้า CSV ต่อคน แสดงเฉพาะเจ้าของ), คำร้อง/ขอเอกสารออนไลน์ (ต่อยอดตัวสร้างฟอร์ม) พร้อมติดตามสถานะ, ประกาศเฉพาะคณะ/สาขา/ชั้นปี (ต่อยอดตัวกรองระดับ), ส่งอีเมลถึงนิสิตเป็นกลุ่ม, ล็อกอินร่วม (SSO: Google Workspace / LDAP ของมหาวิทยาลัย) แทนรหัสผ่านแยก, บัตรนิสิตดิจิทัล + QR, ไฟล์ส่วนตัวต่อคนในโฟลเดอร์ที่ปิดจากภายนอก, ส่งออกรายงานสถิติ (จำนวนตามคณะ/ชั้นปี) — บอกได้ว่าอยากให้ทำข้อไหนก่อน

ข้อจำกัดที่ควรรู้: รูปที่แทรกในเนื้อหามีที่อยู่ในคลังสื่อซึ่งเปิดตรงได้ถ้ารู้ลิงก์ — ไฟล์ที่ต้องปิดจริงให้ใส่ที่กล่อง “ไฟล์” ของเนื้อหา (ธีมส่งให้เอง); การส่งอีเมลลิงก์ใช้ `wp_mail` ของเว็บ (ต้องตั้งค่าอีเมลของเซิร์ฟเวอร์/SMTP ให้ใช้งานได้); เมนูหลักไม่มีลิงก์ `/student/` ให้เอง ให้เพิ่มลงเมนูเอง

## v1.32.0 – ดูแลข้อมูลนิสิต: บันทึกการใช้งาน, ทดสอบอีเมล, ตรวจลิงก์, high-contrast

**1A บันทึกการใช้งานข้อมูลนิสิต (หน้า "Student activity log")**
- บันทึกเหตุการณ์: นำเข้าไฟล์, ส่งออกรายชื่อ, ดาวน์โหลดแถวที่นำเข้าไม่ได้, แก้หลายคนพร้อมกัน, แก้ข้อมูลนิสิต, ลบข้อมูลนิสิต, สร้าง/ลบบัญชี, ส่งหรือแสดงลิงก์ตั้งรหัสผ่าน, เปลี่ยนการตั้งค่า
- เก็บ: เวลา, ผู้ทำ (ชื่อผู้ใช้), ประเภท, รหัสนิสิต/จำนวน, หมายเหตุสั้นๆ — **ไม่เก็บชื่อนิสิต, ไม่เก็บ IP, ไม่เก็บลิงก์รหัสผ่าน**
- ล้างอัตโนมัติรายวันตามจำนวนวันที่ตั้ง (ค่าเริ่มต้น 365, ต่ำสุด 30, สูงสุด 3650) ที่หน้าตั้งค่าพอร์ทัลนิสิต; กรองตามประเภทได้ แบ่งหน้าหน้าละ 30
- เก็บเป็น post type ซ่อน `mcupr_audit` (ไม่ public ไม่อยู่ใน REST); ไม่ได้ทำการบันทึกการ "ดู" ข้อมูลรายคน (เฉพาะการเปลี่ยนแปลง/ส่งออก)
- หมายเหตุ: เมื่อลบข้อมูลนิสิตตามคำขอ (Privacy eraser) แถวบันทึกที่มีเพียงรหัสนิสิตยังอยู่จนครบกำหนดล้าง

**1B อีเมล**
- หน้าตั้งค่าพอร์ทัลนิสิตมีปุ่ม "ส่งอีเมลทดสอบ"; ถ้าอีเมลถึงนิสิตล่าสุดส่งไม่สำเร็จ จะมีแถบแดงบอกเหตุผลที่ระบบอีเมลแจ้ง (ไม่เก็บที่อยู่อีเมล) ในหน้ารายชื่อ/ข้อมูลนิสิต/หน้าตั้งค่า และหายไปเมื่อส่งสำเร็จ
- ทางสำรอง: ปุ่ม "แสดงลิงก์ (ไม่ส่งอีเมล)" ในกล่องบัญชีของนิสิต แสดงลิงก์ตั้งรหัสผ่านให้เจ้าหน้าที่ 5 นาที (เห็นเฉพาะผู้กดเอง) ลิงก์ใช้ได้ครั้งเดียว
- **ยังไม่ได้ทดสอบกับเมลจริง** (ต้องมี SMTP ที่ใช้งานได้บนเซิร์ฟเวอร์ของมหาวิทยาลัย); เทสต์ใช้ตัวจำลอง `pre_wp_mail`

**1C ตรวจลิงก์สวย**
- ถ้า permalink เป็น Plain: แถบแจ้งว่าลิงก์ใช้รูปแบบ `?…=` และแนะนำ "Post name"; ถ้าเป็นลิงก์สวยแต่กฎ `/student/` ยังไม่ถูกบันทึก: แถบเตือนพร้อมปุ่ม "Rebuild the link rules" (ผู้ดูแลเท่านั้น) และคำแนะนำเรื่อง `.htaccess`

**3A high-contrast**
- เดิมเทสต์ใช้ค่า `data-contrast="high"` ซึ่งไม่ใช่โหมดจริง (โหมดจริงคือ wb / yb / by) จึงตรวจเพิ่มด้วยโหมดจริงทั้งสาม: พอร์ทัลนิสิต, หน้าแรกหน่วยงาน, บทความหน่วยงาน, หน้าบุคลากร ที่ 1366/390/320px ด้วย axe

## v1.33.0 – เนื้อหาเฉพาะนิสิต เจาะจงชั้นปี / คณะ / สาขา (แบบ A)

- กล่อง "Who can see this" (ข่าว หน้า กิจกรรม ผลงาน อัลบั้ม วิดีโอ) เมื่อเลือก "เฉพาะนิสิต" มีตัวกรอง: **ระดับ** (เดิม), **ชั้นปี** (1–4 และ 5+), **คณะ / สาขา** (ติ๊กคณะ = ทุกสาขาในคณะ; ติ๊กสาขาเฉพาะได้)
- กติกา: ในกลุ่มเดียวกัน = "หรือ", ข้ามกลุ่ม = "และ", กลุ่มที่ไม่ติ๊ก = ไม่จำกัด; คณะกับสาขาถือเป็นกลุ่มเดียว (คณะที่ติ๊ก หรือ สาขาที่ติ๊ก)
- รายชื่อคณะ/สาขาในกล่องมาจากฐานข้อมูลนิสิต (เฉพาะที่ "กำลังศึกษา") พร้อมจำนวนคน เก็บความจำไว้ 10 นาที (ล้างทันทีเมื่อบันทึก/ลบนิสิต หรือนำเข้า); ค่าที่เคยติ๊กไว้แต่ไม่มีนิสิตแล้วยังแสดงให้เห็นเพื่อยกเลิกได้; ตัวนับสดบอกว่า "นิสิตที่กำลังศึกษาเห็นได้ X จาก Y คน" (ต้องใช้ JavaScript; ไม่มี JS ก็ใช้กล่องได้แต่ไม่มีตัวนับ)
- การเทียบชื่อคณะ/สาขา: ไม่สนตัวพิมพ์เล็กใหญ่และช่องว่างซ้ำ แต่ **สะกดต่างกัน = คนละค่า** (เช่น "คณะพุทธศาสตร์" กับ "พุทธศาสตร์" เป็นสองรายการ ต้องติ๊กทั้งสอง) ถ้าข้อมูลที่นำเข้าสะกดไม่สม่ำเสมอ ควรแก้ที่ไฟล์/ข้อมูลนิสิตก่อน
- นิสิตที่ไม่มีชั้นปี/คณะ/สาขาในข้อมูล จะไม่ผ่านกฎของกลุ่มนั้น; ชั้นปี 6 ขึ้นไปนับเป็น "5+"
- คอลัมน์ "Who sees it" ในรายการสรุปเงื่อนไขให้ (เช่น "ปริญญาตรี · ชั้นปี 1, 2 · คณะพุทธศาสตร์"); เนื้อหาที่เคยตั้ง "เฉพาะนิสิต + ระดับ" ไว้ยังใช้ได้เหมือนเดิม (ดัชนีสร้างใหม่อัตโนมัติ; ตัวเก่า `mcupr_aud_index` ถูกลบ)
- การดึงเนื้อหารายชิ้นด้วยลิงก์ตรงยังได้หน้า 403 สำหรับนิสิตที่ไม่ตรงเงื่อนไข (ไม่แยกข้อความตามเงื่อนไข)

**พบและแก้ระหว่างทดสอบ (สำคัญ)**
1. **ลูปไม่สิ้นสุดเมื่อดัชนีสิทธิ์ยังไม่ถูกสร้าง:** `mcupr_aud_index()` สร้างดัชนีด้วย `get_posts()` ซึ่งไปเรียกตัวกรอง `pre_get_posts` ของตัวเอง ซึ่งขอดัชนีอีก... ไม่สิ้นสุด. เดิมไม่เห็นเพราะดัชนีมีอยู่แล้ว แต่ **เมื่ออัปเดตเป็นรุ่นนี้ชื่อตัวเลือกดัชนีเปลี่ยน** (`mcupr_aud_index2`) จึงจะเจอทันทีบนทุกเว็บ ถ้าไม่แก้ → แก้โดยมีธงกันเรียกซ้อน และไม่แคชค่าระหว่างสร้าง (เทสต์: สร้างดัชนีจากศูนย์ได้ และนิสิตนอกกลุ่มยังถูกกัน)

**หมายเหตุหลังตรวจใน block editor จริง:** กล่องนี้แสดงในแถบข้างของหน้าแก้ไข; แรกใช้ `<details><summary>` ที่มีช่องติ๊กอยู่ข้างใน → axe แจ้ง `nested-interactive` (ปุ่มซ้อนปุ่ม) จึงเปลี่ยนเป็นแถวของคณะ + ปุ่มลูกศรแสดง/ซ่อนสาขา (`aria-expanded`, `aria-label`) และแก้ให้ไม่มี JS สาขาแสดงครบ; เทสต์ e2e ตรวจในโปรแกรมแก้ไขแบบบล็อกและบันทึกด้วยปุ่ม Update
