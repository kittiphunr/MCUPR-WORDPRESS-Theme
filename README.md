# MCUPR WordPress Theme

ธีม WordPress สำหรับเว็บไซต์หน่วยงานภาครัฐ/สถาบันการศึกษา โครงสร้างหน้าเว็บอ้างอิง [www.chula.ac.th](https://www.chula.ac.th/)
(แถบเครื่องมือด้านบน → โลโก้/ชื่อหน่วยงาน → เมนูหลักแบบหลายระดับ → ข่าวเด่น + หัวข้อข่าว → ลิงก์ด่วน → ข่าวล่าสุด → ท้ายเว็บไซต์)

โฟลเดอร์ธีมคือ `mcupr/` — zip โฟลเดอร์นี้แล้วอัปโหลดที่ *Appearance → Themes → Add New → Upload*

## เทคโนโลยี UI

- **Tailwind CSS v4** เป็นแกนของ UI ทั้งหมด — ใส่ utility class ในเทมเพลตโดยตรง (ใช้ `@apply` เฉพาะมาร์กอัปที่ WordPress สร้างเอง เช่น เมนู, เนื้อหาในตัวแก้ไข, pagination, ฟอร์มคอมเมนต์) สี/โหมดมืด/โหมดคอนทราสต์ผูกกับ CSS variables ผ่าน `@theme` จึงใช้ utility ปกติ (`bg-bg`, `text-fg`, `bg-primary` …) ได้ทุกโหมด
- **SweetAlert2** ใช้สำหรับการแจ้งเตือนทั้งหมด: ประกาศคุกกี้/PDPA, ยืนยันการรีเซ็ตการตั้งค่า, toast แจ้งสถานะ (เช่น ขนาดอักษร), เตือนเมื่อค้นหาโดยไม่ใส่คำ — ไฟล์เก็บในธีม (`assets/vendor/`) ไม่โหลดจาก CDN
- ไฟล์ CSS ที่ build แล้ว (`mcupr/assets/css/tailwind.css`) ถูก commit ไว้ ติดตั้งธีมได้เลยโดยไม่ต้องมี Node

### แก้ไขสไตล์

```bash
cd mcupr
npm install
npm run watch    # หรือ npm run build ก่อน commit
npm run vendor   # คัดลอก sweetalert2 จาก node_modules (เมื่ออัปเดตเวอร์ชัน)
```

ต้นฉบับอยู่ที่ `mcupr/src/input.css` — เพิ่ม/แก้ class ในเทมเพลต `.php` หรือ `assets/js/main.js` แล้ว build ใหม่

## หน้าตา (อ้างอิงภาพหน้าจอ chula.ac.th)

หน้าแรก: เมนูหลักลอยบนภาพ Hero เต็มจอ + หัวข้อ 2 บรรทัด + ไทล์ลิงก์ด่วนแบบกระจกฝ้า → สไลด์ข่าวเด่น (เลื่อนด้วยปุ่ม/คีย์บอร์ด ไม่เล่นอัตโนมัติ) → ข่าวสารและกิจกรรม (ปุ่ม “ดูทั้งหมด” ทรงแคปซูล) → แบนเนอร์สีชมพูอ่อน → ท้ายเว็บสีดำแบ่งคอลัมน์

ตั้งค่าที่ Customizer → *MCUPR: Home hero & banner* (ภาพ Hero, หัวข้อ 2 บรรทัด, ข้อความแบนเนอร์ — แยกตามภาษา) เมนู **Quick links** = ไทล์บน Hero, เมนู **Footer links** = คอลัมน์ท้ายเว็บ (รายการระดับบนเป็นหัวคอลัมน์ ระดับรองเป็นลิงก์), เมนู **Utility bar** = ลิงก์นักศึกษา/บุคลากร/ศิษย์เก่า ที่แถบบน

## รองรับหน้าจอ 240px – 4K / ทีวี

| ความกว้าง | พฤติกรรม |
|---|---|
| 240–399px | เลย์เอาต์คอลัมน์เดียว ขอบแคบ ปุ่มและแถบเครื่องมือตัดบรรทัดอัตโนมัติ ไม่มีการเลื่อนแนวนอน |
| 400–899px | มือถือ/แท็บเล็ต เมนูแบบปุ่ม “เมนู” |
| 900–1599px | เดสก์ท็อป (เมนูแนวนอน, ไทล์ Hero 7 ช่อง) |
| ≥1600px | ขยายขนาดอักษรและ UI ทั้งหมดเป็นขั้น: 1600→110%, 1920→125%, 2560→165%, 3200→200%, **3840 (4K)→240%** และขยายความกว้างเนื้อหาเป็น 90rem — ทุกอย่างใช้หน่วย `rem` จึงขยายตามสัดส่วน (ทีวี 4K ที่รายงานเป็น 1920px @2x จะได้ 125%) |

ขนาดสุดท้าย = ขั้นตามหน้าจอ × ปุ่ม A−/A+ ของผู้ใช้ × โหมดทีวี

**โหมดทีวี (10-foot UI)** เปิดอัตโนมัติเมื่อตรวจพบเบราว์เซอร์ทีวี (Tizen, webOS, Android TV/Google TV, VIDAA, Fire TV, HbbTV, Roku, PlayStation/Xbox ฯลฯ) หรือเปิดเองที่แผง “การเข้าถึง → โหมดทีวี”: ตัวอักษรใหญ่ขึ้นอีก 20%, ปุ่ม/เมนูสูงอย่างน้อย 4rem, กรอบโฟกัสหนา 6px, ขอบปลอดภัย (overscan) 4% ซ้าย–ขวา, ธีมมืดโดยค่าเริ่มต้น, และ **เลื่อนโฟกัสด้วยปุ่มลูกศรของรีโมท** (spatial navigation) พร้อมปุ่ม Back (Tizen/webOS) ปิดแผงหรือย้อนกลับ

## Elementor Pro

ธีมรองรับ **Theme Builder** ของ Elementor Pro — ออกแบบ *Header, Footer, Single (โพสต์/หน้า/404), Archive (รวมผลค้นหา)* ได้ที่ Templates → Theme Builder ธีมจะส่งต่อ location เหล่านั้นให้ Elementor ถ้าไม่มีเทมเพลตที่ตรงเงื่อนไขจะใช้เทมเพลต Tailwind ของธีมแทน (ดู `mcupr/inc/elementor.php`)

- หน้า/โพสต์ที่สร้างด้วย Elementor จะแสดงเต็มความกว้าง ไม่มีหัวเรื่องของธีม (หน้าแรกที่เป็น Static Page ที่ออกแบบด้วย Elementor ก็แสดงเฉพาะดีไซน์นั้น)
- **แถบเครื่องมือด้านบน (ภาษา / ขนาดอักษร / โหมดมืด / การเข้าถึง / ค้นหา) ธีมแสดงเสมอ** แม้ใช้ Header ของ Elementor เพื่อให้ฟังก์ชันการเข้าถึงไม่หาย (ปิดได้ที่ Customizer) และมี shortcode ให้วางใน Elementor เอง: `[mcupr_languages]`, `[mcupr_tools]`, `[mcupr_search]`
- ปิดการโหลด Google Fonts ของ Elementor (ไม่ส่ง IP ผู้เข้าชมไปบุคคลที่สาม) — ใช้ Custom Fonts ที่โฮสต์เองแทน
- ข้อจำกัดที่ควรรู้: (1) ปุ่มปรับขนาดอักษรปรับได้เฉพาะขนาดที่เป็น `rem/em` ใน Elementor ให้ตั้งหน่วยตัวอักษรเป็น rem (2) โหมดมืด/คอนทราสต์ปรับได้เฉพาะสีที่เลือกผ่าน **Global Colors** ไม่ใช่สีที่กำหนดเฉพาะวิดเจ็ต (3) เนื้อหาที่สร้างด้วย Elementor ไม่ใช้กล่อง Translations ของธีม — ใช้หน้าแยกตามภาษา หรือปลั๊กอินแปลที่รองรับ Elementor

## ใช้ปลั๊กอินฟรีช่วย เพื่อให้ธีมเบา

| งาน | ปลั๊กอินฟรีที่รองรับ | เมื่อติดตั้งแล้วธีมจะ… |
|---|---|---|
| หลายภาษา | **Polylang** | ใช้ภาษา/URL ของ Polylang (`/en/…`), ปุ่มสลับภาษาดึงจาก Polylang, เมนูแยกตามภาษา (ตำแหน่ง *Main menu* เดียว Polylang แยกให้เอง), เนื้อหาแปลเป็นโพสต์แยกภาษา → **ปิดกล่องแปลภาษา ตัวสลับภาษาในตัว คุกกี้ภาษา และ hreflang ของธีม** (ไม่ซ้ำซ้อน และแก้ปัญหาแคชแบบ `?lang=` ไปในตัว) |
| SEO / Breadcrumb | **Yoast SEO** หรือ **Rank Math** | ใช้ breadcrumb ของปลั๊กอิน (ถ้าเปิดใช้) แทนของธีม |
| ออกแบบหน้า | **Elementor** (+ Pro) | ดูหัวข้อ Elementor Pro ด้านล่าง |

- ธีมยังมีข้อความ UI ครบ 4 ภาษา (ไทย/อังกฤษ/จีน/ญี่ปุ่น) ภาษาอื่นที่เพิ่มใน Polylang จะแสดงข้อความ UI เป็นภาษาอังกฤษ
- ชื่อหน่วยงาน/ที่อยู่/ข้อความ Hero ที่ Customizer ยังตั้งแยก 4 ภาษาได้
- ผู้ดูแลจะเห็นประกาศแนะนำปลั๊กอินที่ยังไม่ติดตั้ง (ปิดได้)
- ถ้าไม่ติดตั้งปลั๊กอินใด ธีมทำงานได้ด้วยตัวเองทั้งหมด (โหมด standalone)
- การย้ายจากโหมด standalone: คำแปลที่เคยกรอกในกล่อง Translations ไม่ถูกลบ แต่ Polylang ไม่อ่านค่านั้น ต้องสร้างโพสต์แปลใน Polylang

## ฟังก์ชัน

| ฟังก์ชัน | รายละเอียด |
|---|---|
| 4 ภาษา | ไทย / English / 中文 / 日本語 สลับด้วย `?lang=th\|en\|zh\|ja` จำค่าด้วยคุกกี้ที่จำเป็น (`mcupr_lang`) ข้อความส่วนติดต่อผู้ใช้อยู่ใน `inc/strings.php` ส่วนเนื้อหาข่าว/หน้า แปลได้ในกล่อง **Translations** ใต้ตัวแก้ไข (หัวข้อ/บทคัดย่อ/เนื้อหา) ถ้าไม่มีคำแปลจะแสดงภาษาหลักพร้อมแจ้งผู้ใช้ และใส่ `lang` ให้ส่วนเนื้อหา (WCAG 3.1.2) พร้อม `hreflang` ใน `<head>` |
| ชื่อหน่วยงาน/ที่อยู่ 4 ภาษา | Customizer → *MCUPR: Organisation & languages* |
| เมนู 4 ภาษา | Appearance → Menus → กำหนด “Main menu (Thai/English/Chinese/Japanese)” ถ้าภาษาใดไม่มีเมนู จะใช้เมนูของภาษาหลัก |
| ปรับขนาดอักษร | A− / A / A+ 5 ระดับ (87.5%–200%) ใช้หน่วย `rem` ทั้งธีม รองรับการขยาย 200% โดยไม่เสียเนื้อหา (WCAG 1.4.4, 1.4.10) |
| โหมดมืด/สว่าง | ปุ่มสลับ + เลือก “ตามระบบ” (`prefers-color-scheme`) ไม่มีการกะพริบเมื่อโหลดหน้า |
| โหมดผู้มีปัญหาทางสายตา | คอนทราสต์สูง (ขาวบนดำ, เหลืองบนดำ, ดำบนเหลือง), สีเทา, ขีดเส้นใต้ลิงก์, ฟอนต์อ่านง่าย, เพิ่มระยะห่างข้อความ, เคอร์เซอร์ใหญ่, ลดการเคลื่อนไหว, ซ่อนรูปภาพ, รีเซ็ตทั้งหมด |

การตั้งค่าการแสดงผลทั้งหมดเก็บใน `localStorage` ของผู้เข้าชม (ไม่ส่งไปเซิร์ฟเวอร์)

## แนวทางตามมาตรฐานเว็บไซต์ภาครัฐ / การเข้าถึง

อ้างอิง **WCAG 2.2 ระดับ AA** (เวอร์ชันล่าสุดของ W3C) ซึ่งเป็นฐานของมาตรฐานเว็บไซต์ภาครัฐของ DGA และ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

- Skip links 3 จุด (เนื้อหา/เมนู/ท้ายเว็บ), landmarks (`header`, `nav`, `main`, `footer`, `role=search`), ลำดับหัวข้อถูกต้อง, breadcrumb
- `lang` ของหน้าและของส่วนที่ต่างภาษา, `hreflang`
- โฟกัสมองเห็นชัด 3px (2.4.7, 2.4.11, 2.4.13), ใช้งานด้วยคีย์บอร์ดได้ทั้งหมด (เมนูย่อยมีปุ่มสลับ, `Esc` ปิด), ไม่มี keyboard trap
- ขนาดเป้าหมายแตะ/คลิก ≥ 44px (2.5.8), คอนทราสต์ข้อความ ≥ 4.5:1 ทั้งโหมดสว่าง/มืด
- แจ้งการเปลี่ยนค่าผ่าน `aria-live`, เคารพ `prefers-reduced-motion`
- ท้ายเว็บไซต์มีลิงก์ นโยบายคุ้มครองข้อมูลส่วนบุคคล, นโยบายคุกกี้, นโยบายการเข้าถึง, แผนผังเว็บไซต์, ติดต่อเรา (ตั้งค่าที่ Customizer → *MCUPR: Policy pages*) และการแจ้งคุกกี้ตาม PDPA ด้วย SweetAlert2 (ใช้เฉพาะคุกกี้ที่จำเป็น)
- ไม่โหลดฟอนต์/สคริปต์จากภายนอก (ไม่มีการส่ง IP ไปบุคคลที่สาม) — ใช้ฟอนต์ระบบ (Sarabun/Noto Sans Thai หากมีในเครื่อง); ต้องการฝังฟอนต์ให้เพิ่ม `@font-face` ของไฟล์ที่โฮสต์เอง

> ธีมช่วยให้ผ่านเกณฑ์ด้านโครงสร้างและการแสดงผล แต่การรับรองตามมาตรฐานต้องตรวจสอบเนื้อหาจริง (alt รูปภาพ, ตาราง, PDF, วิดีโอมีคำบรรยาย ฯลฯ) ด้วย เช่น axe / WAVE และการทดสอบกับ screen reader (NVDA, VoiceOver)

## หมายเหตุการใช้งาน

- หากใช้ปลั๊กอินแคช ให้ตั้ง *vary by query string* หรือ cookie `mcupr_lang` มิฉะนั้นหน้าที่แคชไว้จะแสดงภาษาเดียว
- เปลี่ยนรายการภาษาได้ด้วยฟิลเตอร์ `mcupr_languages` (ลำดับคอลัมน์ใน `inc/strings.php` ต้องตรงกัน)
- ตั้งค่าสีหลักที่ Customizer → Colors (ควรให้ตัวอักษรขาวบนสีหลักมีคอนทราสต์ ≥ 4.5:1)
