# Original (vector) artwork

Source files of the university emblem, kept here for reference and for re-exporting the optimised bitmaps in `mcupr/assets/img/`.
The emblem belongs to Mahachulalongkornrajavidyalaya University – use it only according to the university's rules.
- mcu-logo.svg → mcupr/assets/img/mcu-logo.webp (160px tall, lossy) and favicon.png (48px)
- mcu-seal.svg → mcupr/assets/img/mcu-seal.webp (360px, lossy; used as a faint mask)
